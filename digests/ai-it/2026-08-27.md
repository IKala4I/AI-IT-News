## 🛠️ Інструменти

**Claude [навчився клікати в Chrome сам](https://claude.com/blog/claude-in-chrome-generally-available) — без підтвердження кожної дії**

Розширення доїхало до GA на всіх платних планах, але цікаве не саме GA, а auto mode: дії більше не треба апрувити по одній, їх перед виконанням перевіряє safety-класифікатор — так само, як у Claude Code. Вимикається.

Того ж дня приїхав [окремий браузер усередині Cowork](https://claude.com/blog/cowork-built-in-browser): він не бачить твоїх вкладок, історії й паролів, а ходить по сайтах самостійно. Pro, Max і Team, macOS/Windows/Linux (Linux у беті).

• розширення в Chrome — коли треба, щоб Claude діяв у *твоїй* залогіненій сесії: внутрішні дашборди, легасі-адмінки
• браузер у Cowork — коли треба ізольовано, без твоїх кукі

Проти prompt injection в обох випадках навісили класифікатор і проби, що сканують контент сторінки до дії. Автономний клікер у залогіненому браузері — все одно та штука, де я б спершу звузив список доменів (в організаціях це є в Organization Settings).

**Claude Code [2.1.247](https://code.claude.com/docs/en/changelog) додав `/claude-api cost-optimize` — профайлер витрат на Claude API прямо з CLI**

Команда проходить по коду проєкту і перевіряє важелі економії по одному: кешування, зайві токени, batch, рівень effort, вибір моделі.

```
/claude-api cost-optimize
```

Ще в релізі:
• скіл `/claude-api` доріс до покриття Admin API
• у Sonnet 5 дефолтне вікно auto-compact підняли до повного 1M контексту
• новий тул `SendFeedback` — Claude сам збирає репорт, коли щось ламається

Решта — довгий список фіксів по MCP, плагінах, Remote Control і клавіатурі.

Корисно, якщо в тебе свій продукт на Anthropic API і рахунок росте швидше за трафік. На підписку Claude Code це не впливає — команда саме про API-спенд.

**Codex CLI [0.150.0](https://github.com/openai/codex/releases/tag/rust-v0.150.0) навчився згадувати інші таски через `@` — агент може прочитати, створити або написати в сусідню задачу**

Раніше `@` в Codex був про файли. Тепер із терміналу можна послатись на іншу таску Codex і доручити агенту з нею щось зробити.

Що ще приїхало:
• `Interrupt`-хуки — запускають команду чи MCP-хендлер, коли ти перебиваєш активний хід
• `/copy` тепер із пікером: вся відповідь, окремий блок коду або цитата
• безіменні таски отримують автозаголовки, `/rename` пропонує варіант із розмови
• Vim-мод навчився `.` — повторити останню правку
• untrusted-проєкти більше не підсовують агенту свій `AGENTS.md`

Останній пункт тихий, але найважливіший: `AGENTS.md` у чужому репозиторії — це фактично готовий вектор prompt injection.

**[RealDiff](https://github.com/issacnitin/RealDiff) диффить не код у PR, а реальну поведінку — аргументи й повернені значення методів**

Ідея проста: прогнати ті самі тести на base і на PR, записати трейси викликів і показати, де поведінка розійшлась. Те, що рев'ю очима пропускає.

```
realdiff /path/to/repo --base origin/main --pr HEAD --findings output.json
```

Або без установки залежностей:

```
docker run --rm --volume "$PWD:/workspace" ghcr.io/issacnitin/realdiff:v0.4.0 \
  /workspace --base origin/main --pr HEAD
```

Шість мов: .NET 8 (IL weaving), Java (агент інструментації), Node/TypeScript (Babel), Go (AST rewriting), Rust, Python 3.12+ (`sys.monitoring`). MIT.

Сам не тестив — тул сьогодні тільки виліз на Show HN і ще молодий. Але як другий погляд на рефакторинг, де «нічого не мало змінитись», виглядає точно за адресою.

## 📌 Рухи й безпека

**NVIDIA [домовляється купити Hugging Face](https://techcrunch.com/2026/08/26/nvidia-closes-in-on-hugging-face-acquisition/) — за різними звітами \$12.9–13 млрд**

Статус плаваючий: The Information пише, що угоду вже узгодили, Business Insider — що підписаного договору ще немає і все може розсипатись. Публічно не підтвердила жодна зі сторін.

Для масштабу: у 2023-му HF піднімав раунд за оцінкою \$4.5 млрд, і NVIDIA тоді ж зайшла туди на \$235 млн.

Що буде з Hub, ліцензіями й безкоштовним хостингом ваг — не сказано ніде. А це і є єдине, що тут насправді нас стосується: HF — це `from_pretrained()` у половині пайплайнів і місце, куди щотижня падають нові відкриті ваги.

Поки це новина категорії «стежити», а не «діяти». Але якщо в тебе щось критичне тягнеться з HF прямо в CI — непоганий привід перевірити, чи є локальний кеш або дзеркало.
