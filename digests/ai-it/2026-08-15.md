## 🚀 Моделі

**Anthropic [вмикають вотермарк у тексті Claude](https://www.anthropic.com/news/claude-text-watermark) — глобально з 14 серпня, і на код він не лягає**

Метод — похідна від SynthID-Text у DeepMind: модель підмінює джерело випадковості там, де кілька слів однаково підходять, і лишає патерн, видимий тільки з ключем.

Що це коштує:
• якість виводу не змінюється
• зайвих токенів немає, швидкість практично та сама
• API для детекції обіцяють «скоро», деталей поки нема

Обмеження в пості перелічені чесно: працює на довгих шматках, слабко на коротких фактичних відповідях, і **не працює на коді** та на сильно відредагованому тексті. Моделі, старші за 2 серпня, переводять поступово.

У щоденному кодингу для нас не змінюється нічого — туди вотермарк просто не лягає. Але якщо женеш Claude'ом документацію чи тексти, з якогось моменту це стане детектованим.

**OpenAI [відкрили превʼю Ultrafast](https://community.openai.com/t/ultrafast-mode-preview-gpt-5-6-sol-at-up-to-14x-the-speed-in-the-api/1390344) — той самий GPT-5.6 Sol, але до 750 токенів на секунду**

Це не нова модель і не новий тюн. Інтелект, контекст і якість виводу ті самі, змінюється лише швидкість, з якою прилітають токени: до 14× швидше за Standard, ~750 tok/s проти звичайних ~53.

Крутиться на залізі Cerebras, стартує спочатку в API. Доступ — обмежене превʼю по формі, ціну не назвали взагалі.

Сценарії з анонсу: голос, підтримка, комерція, дев-агенти, фінансовий рісерч, реагування на інциденти.

Для агента в терміналі різниця між 53 і 750 tok/s — це різниця між «пішов заварив чай» і «дивишся, як воно друкує». Поки лишається записатись у чергу.

## 🛠️ Інструменти

**Claude Code [2.1.233](https://code.claude.com/docs/en/changelog) — todo-туди більше не вантажаться на нових моделях, а Bash можна обмежити по памʼяті**

Найпомітніше: `TaskCreate/Get/Update/List` і `TodoWrite` прибрали з Opus 4.8, Sonnet 5, Fable 5, Mythos 5 і новіших. Якщо в тебе воркфлоу зав'язаний на todo-списки — вертається однією змінною:

```bash
export CLAUDE_CODE_ENABLE_TODO_TOOLS=1
```

Ще дві змінні, які варто знати:
• `CLAUDE_CODE_TOOL_MEMORY_LIMIT` — memory cgroup для Bash-команд на Linux, щоб рознесений білд не поклав сесію
• `CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS` — TTL кешу WebFetch (дефолт ті самі 15 хвилин)

Плюс GitLab MR тепер розуміє `--worktree` і `claude agents` (показує як `!N`), полагодили залипання ядра на 100% на Linux із увімкненим сендбоксом і закрили витік NTLM-креденшелів на Windows через NT-префікс шляху.

**OpenAI [викотили Computer History](https://learn.chatgpt.com/docs/customization/computer-history) — Codex і ChatGPT читають твою активність на компі й роблять із неї памʼять**

Те, що анонсували як Chronicle. Деталь, яку варто знати до того, як вмикати: це **не** скріншоти. Пишеться потік подій — кліки, набір тексту, шорткати, переключення застосунків — і лише з тих застосунків та сайтів, які ти сам дозволив.

Події періодично зводяться в текстові саммарі й локальні memory-файли. Сирі івенти лежать локально до 48 годин, памʼять — поки сам не видалиш. Саммаризація йде на серверах OpenAI.

Вмикається в **Settings → Integrations → Computer history**, потрібні увімкнені Memories. Поки лише ChatGPT desktop на macOS, лише Pro/Business/Enterprise, і недоступно в EEA, UK та Швейцарії.

Ідея сильна: агент бачить не тільки репо, а й тікет у браузері. Ціна — івент-лог твого робочого дня їде на чужі сервери.

**[Mole](https://github.com/lajosdeme/mole) — deep research агент у терміналі, який не може вилізти за бюджет**

Go-шний CLI під Apache 2.0, вчора на Show HN. Розбиває питання на підзапити, шукає, витягує цитати, звіряє їх із джерелами і позначає протиріччя. Кожне твердження у відповіді має дослівну цитату.

```bash
brew install lajosdeme/mole/mole
mole research "питання" --usd 0.50
```

Ліміт задається в доларах або токенах; у README стверджують нульове перевищення бюджету на тестовому корпусі. Пошук — Tavily або Brave, модель — Anthropic чи будь-який OpenAI-сумісний ендпоїнт, включно з Ollama, llama.cpp і vLLM:

```bash
mole config set llm.provider anthropic
mole config set llm.model claude-sonnet-5
```

Є аналіз локальних файлів без відправки вмісту назовні і MCP-інтеграція — тобто його можна підчепити субагентом до кодинг-агента.

Головна фіча тут не пошук, а `--usd`. Ресерч-агент, який гарантовано не зʼїсть \$40 за ніч, — це саме те, чого бракує таким тулам.

## 💡 Рецепти

**Autoresearch-цикл: даєш агенту метрику й бенчмарк — і він сам крутить оптимізацію, поки цифра не впаде**

Сьогодні в топі HN [пост про 232× прискорення GPU-кернела](https://news.ycombinator.com/item?id=49309549), зроблене саме так. Цікавий не кернел, а форма: benchmark → profile → verify → improve, у циклі, з відкатом невдалих спроб.

Готова реалізація під Codex — плагін [codex-autoresearch](https://github.com/TheGreenCedar/codex-autoresearch) (Apache 2.0, 830 зірок):

```
codex plugin marketplace add TheGreenCedar/AgentPluginMarketplace --ref main
```

Далі ціль задається у форматі з README:

```
/goal @Codex Autoresearch make the unit tests faster.
Benchmark: npm test -- --runInBand
Wrap that raw command so the benchmark prints METRIC seconds=<number>.
Metric: seconds, lower is better
Checks: npm test
Scope: test runner config and test helpers only
Stop after 5 attempts or 30 minutes.
```

Кожна спроба маркується як `keep` / `discard` / `crash` / `checks_failed`, з нотаткою про гіпотезу і причину відкату.

Сам не тестив; команди взяті з README плагіна — він сторонній, не офіційний від OpenAI. І головне застереження з гілки на HN: багато таких рішень виявились перетренованими під конкретний вхід і ламались на інших даних. Тому `Checks:` і `Scope:` — не формальність.
