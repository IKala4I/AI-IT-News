## 🚀 Моделі

**OpenAI [вперше назвали наступну модель — Astra](https://openai.com/index/ten-advances-in-mathematics/): її внутрішня версія розв'язала 10 задач, у яких не було прогресу щонайменше десять років**

Головне тут не самі результати, а формат публікації. Кожен доказ приїхав з Lean 4 формалізацією в репозиторії [openai/ten-proofs](https://github.com/openai/ten-proofs) — Apache-2.0, Lean 4.32.0 з mathlib. Плюс окремим PDF викладені reasoning walkthroughs, зібрані з неопублікованих трас міркування.

Заявлена вартість — менш ніж \$2000 токенів за ціною Sol на кожну задачу. Simon Willison справедливо додає: скільки задач з'їли ті самі \$2000 і не дали розв'язку, ніхто не каже.

На HN уже висить [спроба спростувати](https://news.ycombinator.com/item?id=49140869) один з результатів — про Connes' Rigidity Conjecture. У коментарях ставляться прохолодно: авторка паралельно публікувала і доказ гіпотези Рімана.

Спробувати сьогодні нічого — Astra ніде не доступна. Але машинно-перевірюваний сертифікат замість прес-релізу з бенчмарком — це та планка, якої від інших лаб теж варто чекати.

#models

## 🛠️ Інструменти

**[DeepSeek-Reasonix](https://github.com/esengine/DeepSeek-Reasonix) — термінальний кодинг-агент одним Go-бінарником, зібраний навколо prefix cache DeepSeek**

```bash
npm install -g reasonix
reasonix code my-project
```

Або без глобального встановлення:

```bash
npx reasonix code
```

Провайдери і моделі описуються конфігом (`~/.reasonix/config.json` плюс оверрайди в `<project>/.reasonix/`), тож підключити можна будь-який OpenAI-сумісний ендпоінт, не тільки DeepSeek. Плагіни живуть окремими процесами і спілкуються по stdio JSON-RPC, сумісно з MCP. Ліцензія MIT.

Продають одну ідею: стабільність кешу — не фіча, яку вмикають, а інваріант, навколо якого побудований весь цикл агента. У README наводять прогін користувача: 435M вхідних токенів, 99.82% попадання в кеш, ~\$12 замість ~\$61.

Цифри — з README автора, сам не тестував. Сьогодні репозиторій у GitHub trending з +389 зірок за добу.

Позавчора в дайджесті були \$0.0028 за мільйон на cache hit у DeepSeek. Харнес, який реально в цей кеш влучає, — рівно та друга половина цієї ціни.

## 💡 Рецепти

**Simon Willison виклав [smevals](https://simonwillison.net/2026/Jul/31/smevals/) — eval-сьют, який кодинг-агент вивчає і будує собі сам**

Точка входу нетипова: ти не читаєш доки, а віддаєш їх агенту.

```bash
uvx smevals docs
```

Команда виплюне README прямо в контекст — далі просто кажеш «побудуй мені eval-сьют». Готовий eval — це директорія з YAML-файлами. Запуск і розбір:

```bash
uvx smevals run path-to-eval/ -m gpt-5.5 -m claude-opus-4.6
uvx smevals grade path-to-eval/
uvx smevals serve path-to-eval/
```

Словник простий: eval → tasks → configs → runs. Найцікавіше в configs: конфіг задає не лише модель, а й системний промпт, параметри та навіть agent harness. Тобто A/B ганяється не тільки між моделями, а й між двома версіями твого власного промпту.

`smevals build` збирає той самий звіт статичним HTML — можна покласти куди завгодно.

▶ [Дивитись приклад звіту](https://static.simonwillison.net/static/2026/smevals-haiku-build/#/haiku)

Зроблено з дослідницькою лабою Prime Radiant, ліцензія MIT. Команди — з поста Simon і README репозиторію, сам не ганяв.

Це рівно та штука, якої бракує, коли міняєш промпт у продакшн-пайплайні й спираєшся на «ну, здається, стало краще».
