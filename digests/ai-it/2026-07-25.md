## 🛠️ Інструменти

**Claude Code Desktop тепер [бачить і керує iOS Simulator](https://code.claude.com/docs/en/desktop-ios-simulator) прямо в сесії** — публічна бета для macOS

Просите зібрати, запустити чи перевірити застосунок — і поруч із чатом відкривається панель з живим стрімом симулятора. Claude сам ставить білд, тапає по екрану і звіряє власні правки, а ви можете одночасно тикати в той самий девайс руками.

Панель керує симулятором напряму, без macOS-дозволів Accessibility і Screen Recording, потрібних для звичайного computer use. До 4 пристроїв на сесію, кожна паралельна сесія — зі своїм окремим девайсом.

Потрібні Claude Desktop 1.24012.0+, Xcode з iOS-платформою; доступно на Pro, Max і Team (не Enterprise), тільки в локальних сесіях.

Якщо досі перемикались між Claude Code і Xcode вручну, щоб перевірити екран — тепер агент сам прожене flow і покаже результат наживо, а не опише словами.

## 💡 Рецепти

**Sakana AI оновили [Fugu-Ultra до v1.1](https://sakana.ai/fugu-1-1-claude-code-interface/) і додали ендпоінт, сумісний з Claude Code**

Fugu — не окрема модель, а мультиагентний роутер: один API-виклик сам розподіляє задачу між пулом фронтир-моделей і координує їх між собою. У v1.1 — приріст до 7.9 бала на бенчмарках (найпомітніше на ProgramBench і Terminal Bench 2.1), ціна та сама, що в v1.0.

Головне для CLI: Fugu тепер можна підключити прямо як бекенд для Claude Code.

```bash
curl -fsSL https://sakana.ai/fugu/install | bash
claude-fugu
```

Або вручну, змінними середовища:

```bash
export ANTHROPIC_BASE_URL="https://api.sakana.ai"
export ANTHROPIC_AUTH_TOKEN="fish_..."   # ваш Sakana-ключ
export ANTHROPIC_DEFAULT_OPUS_MODEL="fugu-ultra"
claude
```

Команди — з офіційного getting-started Sakana, сам не тестив.

Якщо хочеться прогнати задачу через кілька фронтир-моделей одразу замість однієї, не міняючи звичний інтерфейс Claude Code — виглядає як швидкий спосіб спробувати без переписування воркфлоу.
