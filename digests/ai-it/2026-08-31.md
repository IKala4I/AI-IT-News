## 🚀 Моделі

**Alibaba виклали [Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next) — це не флагман, а превʼю архітектури майбутнього Qwen4**

За цифрами з картки моделі: 125B загальних параметрів, з яких активні 6B, плюс окремо 51B n-gram-ембедингу і 4B MTP. Контекст — 262 144 нативно, розтягується до 1M через YaRN. Ліцензія `qwen-community-1.0`, модель мультимодальна (текст + зображення).

Найцікавіше — не бенчмарки, а те, що всередині:
• гібридна увага з Gated DeltaNet і Qwen Sparse Attention (QSA)
• Gated Residual streams з модульованим потоком інформації
• той самий n-gram-ембединг як спосіб масштабувати параметри дешево
• 48 шарів зі змішаними патернами уваги

Запускати автори радять не через голий `transformers`, а через vLLM, SGLang або KTransformers.

Читається це як свідомий хід: команда викладає архітектуру заздалегідь, щоб автори квантизацій та інференс-движків встигли підготуватись до Qwen4, а не ловили його постфактум. Якщо ти тримаєш щось локально — саме час подивитись, чи твій стек це переварить.

## 🛠️ Інструменти

**uv [навчився дедуплікувати окремі файли](https://github.com/astral-sh/uv/pull/21327) всередині wheel-кешу — мінус 545 MiB на машині автора**

Раніше дедуплікувались тільки wheel-и цілком. Тепер кожен файл усередині складається в бакет `files-v0` під BLAKE3-хешем, а на місце повертається хардлінком.

Цифри з PR:
• ~545.2 MiB економії, приблизно 10% кешу
• холодна інсталяція повільніша на 3-4%, найгірший випадок — wheel PyTorch, 5.18%
• на теплому кеші різниця в межах похибки

Змерджив Charlie Marsh сьогодні, поки що за прапорцем `--preview-features content-addressed-cache`.

Якщо в тебе CI ганяє десятки Python-оточень або локально лежить розгодований кеш після експериментів з ML-бібліотеками — це той компроміс, який майже завжди вигідний. Але прапорець ще preview, тож у прод-пайплайн я б поки не тягнув.

## 💡 Рецепти

**Рецепт: памʼять агента як звичайний zip — [memoryfield](https://calpaterson.com/memoryfields.html) від Cal Paterson**

Ідея проста до нахабства: не будувати пайплайн з чанкінгу, графів і векторної БД, а домовитись про формат файлу.

> Memory should be a data format, not a multi-stage process.

Memoryfield — це zip, у якому лежать markdown-сторінки (за бажанням з YAML frontmatter) і необовʼязковий SQLite-індекс для семантичного пошуку. Агент пише прозою, без чанкінгу; пошук віддає релевантні сторінки за один виклик, без обходу графа.

Ставиться трьома командами:

```
ollama pull nomic-embed-text
uv tool install git+https://github.com/calpaterson/memoryfield-tool
npx skills add calpaterson/memoryfield-skill -g -y
```

Є [специфікація](https://github.com/calpaterson/memoryfield-spec/blob/main/SPEC.md) в форматі RFC і [демо-memoryfield](https://blobs.calpaterson.com/soapstones.memoryfield.zip), щоб покрутити на чужих даних, не наповнюючи свій.

Сам не тестив — команди взяв дослівно з посту автора; сьогодні висить на першій сторінці HN зі 120+ апвоутами.

Головний плюс — формат відкритий і переносний: памʼять не залипає в конкретному тулі й переїжджає між агентами разом із файлом. Позаду на цьому ж тижні був Lemmalog з Datalog-базою — тут підхід рівно протилежний, мінімум механіки.

**Рецепт: підключити [офіційний MCP «Сільпо»](https://ai-factory.silpo.ua/docs/mcp) до Claude Code однією командою**

Рідкісний випадок, коли український ритейл віддає нормальний MCP, а не пресреліз про інновації.

```
claude mcp add --transport http silpo https://mcp.silpo.ua/mcp
```

Для Claude Desktop те саме через конфіг:

```json
{
  "mcpServers": {
    "silpo": {
      "url": "https://mcp.silpo.ua/mcp"
    }
  }
}
```

Усередині 39 тулів: пошук товарів, каталог, кошик, історія замовлень, доставка, бонуси й промо. Авторизація — OAuth 2.1 з PKCE: при першому конекті відкривається браузер, далі клієнт сам оновлює токени, а JWT «Сільпо» до AI-клієнта не потрапляє взагалі.

Офіційна фіча, все з документації.

І окремо — дедлайн на сьогодні: реєстрація на [хакатон «Сільпо» AI Factory](https://dou.ua/calendar/58019/) закривається 31 серпня, сам він онлайн і безплатний 1 вересня, призовий фонд 100 000 грн. Умова — будувати агентів саме на офіційному MCP.

Як на мене, найкращий привід нарешті написати свого першого MCP-клієнта на задачі, де результат видно одразу.
