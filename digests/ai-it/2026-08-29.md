## 🛠️ Інструменти

**Claude Code [2.1.251](https://code.claude.com/docs/en/changelog) навчився перехоплювати зміну моделі — і тихо закрив дірку з симлінками**

Два нових хук-івенти: `PreModelSwitch` спрацьовує до застосування перемикання і може його заблокувати, `PostModelSwitch` — після, включно зі змінами, які Claude Code робить сам. Матчер — канонічна назва моделі, хук отримує `from_model` і `to_model` замість звичного `model`.

Дрібніше, але корисне:
• у `/cost` з'явився рядок про prompt cache за сесію — hit ratio, промахи, скільки токенів перекешовано, warm/cold
• у `/usage` — смуга ліміту витрат

А в списку фіксів дві речі, заради яких і варто оновитись сьогодні: файлові тули (Read, Write, Edit) ходили за симлінками і могли читати й писати поза дозволеними локаціями, а команди плагінів могли вказувати за межі теки плагіна.

Хуки — це приємно, але оновлюйся ти саме через симлінки.

**[StemDeck](https://github.com/stemdeckapp/stemdeck) розбирає трек на 6 доріжок локально — Apache-2.0 і без жодного аплоаду**

Під капотом Demucs `htdemucs_6s` від Meta AI: вокал, барабани, бас, гітара, піано й решта. Опційно лід і бек-вокал розводяться окремо через UVR-MDX-NET Karaoke 2. На вхід — YouTube-лінк або MP3, WAV, FLAC, OGG/Opus, MP4, M4A.

Torch-девайс визначається сам: CUDA на NVIDIA, MPS на Apple Silicon, CPU як фолбек. Перший запуск тягне ~170 MB ваг.

```bash
git clone https://github.com/stemdeckapp/stemdeck stemdeck && cd stemdeck
./run.sh setup     # ffmpeg + uv, далі uv sync
./run.sh start     # http://localhost:8000
```

Є і Docker-образ, і десктопні шели на Tauri v2 під macOS та Windows.

Автори в README чесно порівнюють себе з хмарними сервісами і програють їм у якості моделей та швидкості на слабкому залізі. Але якщо треба мінус чи окрему басову лінію без відправки файлу кудись — це рівно те.

## 💡 Рецепти

**Рецепт: пам'ять агента як Datalog-база — [Lemmalog](https://github.com/JordyZomer/lemmalog) як MCP-сервер у Claude Code**

Ідея з [розбору автора](https://pwning.systems/posts/llm-memory-program-analysis/): замість того, щоб перечитувати весь транскрипт, факти витягуються на вході, а висновки виводяться правилами. Змінилась передумова — залежні висновки перераховуються самі, а не воскресають уже спростованими.

Цифри звідти ж, LongMemEval: ~2 700 токенів на питання проти ~104 000 у full-context, F1 0.463 проти 0.222.

```sh
cargo build --release --features mcp

# Claude Code, project або user scope
claude mcp add lemmalog -- $(pwd)/target/release/lemmalog-mcp

# щоб пам'ять пережила рестарт сесії
claude mcp add lemmalog --env LEMMALOG_MCP_PATH=/tmp/lemmalog.snapshot -- \
  $(pwd)/target/release/lemmalog-mcp
```

Усього 12 тулів. Робочий мінімум: `lemmalog_observe` кладе факти рядковим протоколом, `lemmalog_query` питає, `lemmalog_why` віддає дерево доведення аж до вихідного епізоду.

Команди — з README репозиторію, сам не ганяв. Автор при цьому чесний: на частині категорій LongMemEval простіші бейзлайни його обходять.

#recipes

**Рецепт: не дати сесії Claude Code злізти з моделі, яку ти вибрав**

`PreModelSwitch` з учорашнього 2.1.251 спрацьовує до застосування зміни моделі, і `exit 2` у скрипті її блокує — текст зі stderr стає повідомленням про блокування.

```json
{
  "hooks": {
    "PreModelSwitch": [
      {
        "matcher": "claude-opus-5",
        "hooks": [
          {
            "type": "command",
            "command": "/path/to/validate-model-switch.sh",
            "timeout": 30
          }
        ]
      }
    ]
  }
}
```

Матчер — канонічна назва моделі, на яку перемикаються; працює і регулярка `.*opus.*`, і перелік через `claude-opus-4-6|claude-opus-5`. На stdin скрипт отримує `from_model` і `to_model`.

Одна пастка з документації: хук, який не вклався в таймаут, теж блокує перемикання. Тримай скрипт швидким.

Офіційна фіча, конфіг і семантика exit-кодів узяті з [доки по хуках](https://code.claude.com/docs/en/hooks). Якщо хочеться лише бачити факт зміни, а не блокувати — той самий конфіг, але на `PostModelSwitch`, який блокувати не вміє.

## 📌 Рухи й безпека

**OpenAI [розриває контракт із Cursor](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/) після покупки редактора SpaceX — прямий доступ до GPT вимикається 12 листопада**

Що лишається робочим:
• свій власний OpenAI API key усередині Cursor
• розширення OpenAI для IDE
• решта провайдерів у пікері моделей — Anthropic, Google та інші

Причина від OpenAI — довіра: спрацював пункт контракту про зміну власника, плюс досвід з попередніми контрактами компаній Маска. Співзасновник Cursor Michael Truell у відповідь каже, що на моделі OpenAI припадає близько 5% трафіку Cursor і що команди «в перемовинах».

У [треді на HN](https://news.ycombinator.com/item?id=49486172) на 714 балів головна реакція — не паніка, а «а я вже пішов»: перелічують VS Code з Claude Code і Codex, Zed, JetBrains Air, OpenCode.

Якщо ти в Cursor і саме на GPT — до листопада є час або перевести все на свій ключ, або спокійно подивитись альтернативи. Панікувати нема чого, планувати варто.

**Патч у публічному PR тепер [сам себе видає](https://anil.recoil.org/notes/rumour-is-the-exploit) — на cohttp експлойт приїхав за 10 хвилин після коміту**

Anil Madhavapeddy отримав приватний репорт про path traversal у cohttp 6.3.0 — некоректна нормалізація percent-encoded розділювачів шляху — і відкрив публічний PR із фіксом.

Хвилин через десять у логах його сервера пішли проби рівно з тим патерном обходу. Тобто за публічними репозиторіями вже сидять автоматичні спостерігачі. Власні агенти автора зробили робочий експлойт менш ніж за хвилину.

Найнеприємніша цифра — від мейнтейнера rclone Ніка Крейг-Вуда: за перші 10 років проєкту прийшло близько 20 security-репортів, за останній місяць — понад 40.

Висновок для будь-кого зі своїм опенсорсом: сам факт «тут десь є path traversal» уже дає агенту достатньо напрямку. Ембарго на розкриття у старому вигляді просто перестало працювати.
