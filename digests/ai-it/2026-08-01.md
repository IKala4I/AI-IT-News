## 🛠️ Інструменти

**MCP [став stateless](https://modelcontextprotocol.io/specification/2026-07-28/changelog) — у ревізії 2026-07-28 прибрали сесії, `initialize` і заголовок `Mcp-Session-Id`**

Що змінилось по суті:
• кожен запит — окремий HTTP POST; версія протоколу і capabilities їдуть у `_meta`
• GET-ендпоінт і resumability через `Last-Event-ID` прибрані
• зʼявився `server/discover` — сервер сам оголошує підтримувані версії й capabilities
• зміни списків тулів приходять одним довгим стрімом `subscriptions/listen`
• Roots, Sampling і Logging позначені deprecated

Практичний наслідок: MCP-сервер тепер пишеться як звичайна stateless HTTP-ручка і нормально живе на serverless — стан між викликами тримати не треба. Кому потрібен стан, віддає власні хендли як звичайні аргументи тула.

Зворотна сумісність є, але клієнти мають фолбечити на старий `initialize` — тож найближчі місяці будуть із приколами.

Це та зміна, після якої написати власний MCP-сервер — задача на вечір, а не на вихідні.

**Y Combinator [відкрили qm](https://github.com/yc-software/qm) — self-hosted харнес для флоту агентів, MIT**

```bash
npm exec --yes --package=@yc-software/qm@latest -- \
  qm init . --org <slug> --target <fly-or-aws>
npm install
```

Ідея не в персональному асистенті, а в робочому просторі. У кожної людини — своя ізольована пісочниця з власною памʼяттю, файлами й правами; поруч живуть спільні кімнати, привʼязані до Slack-каналів і проєктів.

• одна ідентичність між Slack і вебом
• харнес змінний: Claude Code, Codex, OpenCode, Pi
• cron-джоби і watch-и для фонової роботи
• стек — TypeScript на Fastify, Postgres, Slack Bolt, Vite + Lit
• деплой на Fly або AWS

Сьогодні в топі HN. Найцікавіше — саме розділення скоупів: агентні платформи зазвичай або суто персональні, або суто командні, а тут і те, і те з реальною ізоляцією прав.

**[WASTE](https://github.com/sqliteai/waste) ганяє Kimi K3 на 2.78T параметрів на MacBook з 64GB — експерти стрімляться з NVMe**

```bash
git clone https://github.com/sqliteai/waste && cd waste
make
waste run ~/models/k3.waste "What is the capital of Italy?"
```

Логіка MoE: на токен активується близько 4% ваг. WASTE тримає резидентно тільки транк моделі, а потрібних експертів дочитує з диска в оптимізованому лейауті.

• K3: 0.45–0.62 токена/с, мінімум 29 GB RAM, контейнер 982 GiB на NVMe
• Kimi-Linear 48B: 10.7 токена/с, 19 GiB, мінімум 1.87 GB RAM
• завантаження моделі — 20 секунд

Чистий C11, без BLAS, CUDA і Python у рантаймі, Apache 2.0. Конвертація ваг K3 — разова операція на ~4.7 години. Автори попереджають: на зовнішньому USB-диску все стає в 13 разів повільніше.

Пів токена на секунду — це не для роботи. Але для довгих фонових задач на локальній фронтир-моделі варіант уже не фантастичний.

**Microsoft [виклали Flint](https://github.com/microsoft/flint-chart) — мову опису графіків, яку агент може згенерувати, а людина відредагувати**

```bash
npx -y flint-chart-mcp
```

Проблема очевидна кожному, хто просив агента побудувати графік: він мусить нагенерувати простирадло Vega-Lite чи ECharts зі шкалами й осями — і регулярно там помиляється. Flint приймає компактний спек із семантичними типами (`Quantity`, `Country`, `Rank` — усього 70+), а решту компілятор виводить із даних сам.

Один і той самий спек компілюється у Vega-Lite, ECharts, Chart.js, Plotly та Excel. Команда вище підключає MCP-сервер до Claude Code чи Cursor; для використання як бібліотеки — `npm install flint-chart`. Ліцензія MIT.

Якщо агент у тебе регулярно малює графіки і ти так само регулярно правиш за ним конфіг осей — це рівно про цей біль.

## 💡 Рецепти

**Simon Willison зібрав [llm-mcp-client](https://simonwillison.net/2026/Jul/31/stateless-mcp/) — чіпляє будь-який MCP-сервер до CLI `llm` одним прапорцем**

```bash
llm install llm-mcp-client
llm -T 'MCP("https://datasette.simonwillison.net/-/mcp")' 'count the notes'
```

Подивитись, що сервер узагалі вміє, ще до підключення — окремим тулом:

```bash
uvx mcp-explorer list https://agentic-mermaid.dev/mcp
uvx mcp-explorer call https://agentic-mermaid.dev/mcp render_svg \
  -a source 'graph TD; A-->B' -a options '{"padding":24}'
```

Обидва зʼявились рівно тому, що зі stateless-специфікацією MCP-клієнт пишеться в кілька десятків рядків замість повноцінного менеджера сесій.

`llm-mcp-client` сам Simon називає alpha — команди взяті з його поста, я не тестував. `mcp-explorer` виглядає самодостатнішим: швидко оглянути схему чужого MCP-сервера, не чіпляючи його до агента.

Юзкейс, заради якого це варте уваги: MCP-сервер, написаний під Claude Code, тепер можна смикнути з баш-скрипта чи з крону — взагалі без агента.
