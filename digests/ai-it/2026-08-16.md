## 🛠️ Інструменти

**[Waku](https://waku.sh) — нативний десктоп, у якому всі твої агентські CLI живуть в одному вікні**

Rust на GPUI, ліцензія GPL-3.0. Підхоплює ті CLI, які вже стоять і залогінені:
• Claude Code
• Codex CLI
• Cursor CLI
• Amp, OpenCode, Grok Build, Pi

Сесії, транскрипти, активність тулів і чекпоінти — локально, без ремоут-сервісу. Rewind зроблений через git і відкочує код разом із розмовою з провайдером, а не окремо. Є черга повідомлень і перемикання моделі та reasoning-налаштувань на льоту.

macOS і Linux (Wayland та X11); browser і computer-use поки тільки на макі.

Якщо ганяєш кілька агентів паралельно і задовбався тримати п'ять терміналів — це саме та коробка. Git-rewind окремо тішить: коли агент наламав дров у трьох файлах, відкат не залишає розмову розсинхроненою з кодом.

## 💡 Рецепти

**Simon Willison [зібрав CORS Chat](https://simonwillison.net/2026/Aug/15/cors-chat/) — браузерний клієнт до будь-якого OpenAI-сумісного ендпоінта**

Піднімаєш локальну модель у LM Studio з увімкненим CORS:

```
lms server start --cors
```

Далі відкриваєш `https://tools.simonwillison.net/cors-chat`, вставляєш Base URL (у LM Studio за замовчуванням `http://localhost:1234/v1`) — і все. Ключ опційний, для OpenRouter є поле bearer-токена.

Що вміє: кілька збережених ендпоінтів, історія і конфіг у браузері, експорт розмови в JSON, показ reasoning-трейсу і прогресивний рендер SVG прямо під час стріму.

Сам не тестив. Simon ганяв це на Qwen 3.8 27B у LM Studio (M5 MacBook Pro і NVIDIA DGX Spark) та на OpenRouter — пише, що обидва працюють. Флаг `--cors` офіційний, описаний у доках LM Studio.

Зручно, коли треба швидко помацати локальну модель або чужий OpenAI-сумісний ендпоінт і не хочеться ставити заради цього ще один клієнт.

## 📌 Рухи й безпека

**[jit](https://github.com/jitpass/jit) прибирає плейнтекстові секрети з ноута — у зашифрований vault за Touch ID**

Проблема стара: `.env`, `~/.aws/credentials`, експорти в шелі й конфіги лежать відкритим текстом, і будь-який процес під твоїм юзером їх читає. Включно з агентом, якому ти щойно дав доступ до шела.

jit сканує машину, переносить знайдене у локальний vault і переписує файли так, щоб тули далі працювали:

```
brew install jitpass/tap/jitpass
jit scan
jit vault init
jit migrate
jit run -- npm run dev
```

Віддає секрети трьома шляхами: env-змінною в один процес через `execve`, нативними протоколами (AWS `credential_process`, docker helper, kubectl plugin) і FIFO на 0600 для тулів, які вміють тільки читати файл. Гейтів два — розблокування vault на 5 хвилин і окремий консент із назвою застосунку, що просить ключ.

Тільки macOS на Apple Silicon. Ліцензія PolyForm Perimeter: безкоштовно для особистого та внутрішнього використання, але це не опенсорс.
