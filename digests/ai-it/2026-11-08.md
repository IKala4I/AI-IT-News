## 🛠️ Інструменти

**Cursor [тепер вміє голосові дзвінки з агентами](https://cursor.com/changelog/voice-chat): говориш з ним, поки він працює, і чуєш короткі звіти замість простирадл тексту**

**Коли знадобиться:** довга задача крутиться в хмарі, а ти далеко від клавіатури. Питаєш, що змінилось у диффі чи як іде прогін, і голосом даєш наступну задачу.

**Як виглядає:** очищаєш поле вводу в чаті агента і тиснеш кнопку з хвилькою «Start voice chat» на місці Send. З айфона досить сказати «Hey Siri, call Cursor». Працює в Agents Window, IDE, вебі та Cursor для iOS.

**+** агентом можна керувати без клавіатури, навіть з Lock Screen
**−** голос обробляє Grok Voice, а нульове зберігання даних буде тільки з Privacy Mode. Є [денний ліміт дзвінків](https://cursor.com/docs/agent/voice-chat), але скільки саме, не кажуть

Зручно, коли хмарний агент працює, а ти йдеш по каву. З кодом під NDA спершу ввімкни Privacy Mode.

## 📌 Важливо знати

**«Yes, and don't ask again» у Claude Code [записує точну команду разом із паролем](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again) у `.claude/settings.local.json`, а Apiiro знайшла 1 122 такі файли з секретами в публічних репо на GitHub**

• файл лежить прямо в проєкті, і від коміту його береже лише глобальний gitignore. На новій машині, в контейнері чи в скопійованій папці він спокійно їде в репо
• за даними Apiiro, у 539 з 1 105 репо зі справжнім секретом файл змінював коміт, співавтором якого був сам Claude ([обговорення на HN](https://news.ycombinator.com/item?id=50407882))

Перевір, чи файл не потрапив у твої репо:

```
git ls-files .claude/
```

Знайшовся з секретом? Спершу зміни пароль чи токен, потім:

```
git rm --cached .claude/settings.local.json
echo ".claude/settings.local.json" >> .gitignore
```

І не вписуй секрети прямо в команди, тримай їх у змінних середовища.
