Актуальні цифри з картки моделі в доках:
• вхідні — \$4/M, це мінус 20%
• вихідні — \$20/M, це мінус 33%

• контекст 1 050 000 токенів, до 128 000 на вивід

Ціна позначена як промо і, за текстом доків, тримається щонайменше до 21 листопада 2026. Тобто це не «назавжди», а вікно на три місяці.

Сама модель не змінилась — той самий Sol, просто дешевший. Найпомітніше це на агентних сесіях, де вихідних токенів багато: мінус третина на виводі відчутніша за мінус п'яту на вході.

## 🛠️ Інструменти

**Claude Code [2.1.239](https://code.claude.com/docs/en/changelog) — полагодили тихе подвоєння рахунку на Bedrock і додали `/claude-api upgrade`**

Головний фікс у списку: за проксі, який зрізає заголовок `Content-Type` у відповіді, стрімінг на Bedrock ламався — і кожен хід мовчки переганявся ще раз, вже без стріму. Рахунок за API при цьому подвоювався, і зовні це ніяк не було видно.

Ще з корисного:
• `/claude-api upgrade` — мігрує Python-проєкт з `anthropic` 0.x на 1.x (таймаути тепер `anthropic.Timeout`, не `httpx.Timeout`)
• на Windows зʼявився cross-session messaging: сесії на різних машинах бачать одна одну через `ListAgents` і пишуть через `SendMessage`, як давно вміють macOS і Linux
• плагіни, синхронізовані з claude.ai, показуються як `name@synced` і більше не перебивають однойменний локально встановлений
• `/goal` перестав довбати чек-інами кожні 30 хвилин — тепер бекофф 30 хв → 1 год → кожні 2 год
• WebFetch більше не тримає протухлий контент сторінки в памʼяті всю сесію

Слідом вийшла 2.1.240, але там тільки «bug fixes and reliability improvements».

Якщо ти на Bedrock — це той рідкісний фікс, який варто застосувати сьогодні і піти подивитись на рахунок за минулий місяць.

**Simon Willison [зарелізив llm-openrouter 0.7](https://github.com/simonw/llm-openrouter/releases) — три серверні тули просто з CLI**

Плагін підтягнули під LLM 0.32, моделі перевели на реалізацію Responses API від OpenRouter, і показ reasoning-трейсів нарешті працює.

Головне — зʼявились серверні тули `Shell`, `WebFetch` і `WebSearch`. Вмикаються прапорцем `-T`, крутяться на боці OpenRouter, тобто нічого локально ставити не треба. Приклад із README:

```bash
llm -m openrouter/openai/gpt-5.2 \
  -T 'WebSearch(max_results=3)' \
  'key events on march 1st 2025'
```

`WebSearch` бере ще `engine`, `max_uses`, `max_total_results`, `search_context_size`, `max_characters`, `user_location`, `allowed_domains` і `excluded_domains`. Модель сама вирішує, коли шукати.

Зручно, коли треба швидко зібрати чернетку рісерчу в терміналі й не тягнути окремий пошуковий API з ключами.

**[Munder Difflin](https://munderdiffl.in/) — локальний харнес, що крутить дюжину CLI-агентів як «офіс твоїх клонів»**

Ставиться як звичайний застосунок на macOS, Windows і Linux, обгортає вже наявні CLI-агенти й дає їм працювати паралельно. Підтримує 12 провайдерів: Claude Code, Codex, Grok, Kimi Code, Antigravity, Qwen, Gemini CLI, OpenCode, Crush, Pi, Copilot і Cursor. Ключі та підписки — свої.

Ядро під MIT і безкоштовне, білди лежать у [релізах](https://github.com/chaitanyagiri/munder-difflin/releases/latest). Платне тільки навколо: Cloud (окрема VM, щоб клони крутились 24/7) і Network (командний режим із end-to-end шифрованими повідомленнями між клонами).

Назва — жарт із «Офісу», але ідея проста: замість одного агента в терміналі тримати кілька, кожен на своїй задачі. На HN 180 балів за пів дня.

## 💡 Рецепти

**Скіл [`/debuzz`](https://github.com/adnanakil/nobuzz) віддає відповідь Claude іншій моделі, щоб та переказала її людською мовою**

Ідея чесна: жодним промптом до кінця не вилікувати схильність Claude писати «ось де стає цікаво», «і третє — це взагалі кікер». Тож скіл бере попередню відповідь Claude, скидає її в тимчасовий файл і проганяє через Antigravity CLI (`agy`), а результат друкує дослівно — без «причісування» назад у той самий голос.

```bash
git clone https://github.com/adnanakil/nobuzz
mkdir -p ~/.claude/skills
cp -r nobuzz/debuzz ~/.claude/skills/
```

Потрібен `agy`:

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

Далі один раз запустити `agy`, щоб пройти Google Sign-In. На Windows — `irm https://antigravity.google/cli/install.ps1 | iex`.

Використання: `/debuzz [mode] [text]`, три режими —
• `colleague` (дефолт) — той самий зміст, усі шляхи до файлів і код на місці, нуль театру
• `manager` — що сталося, чому важливо, що далі; втричі коротше, без коду
• `director` — 3-5 речень: результат, вплив, запит

Без аргументів перекладає останню відповідь Claude. Тригериться і на фрази штибу «say that in normal english».

MIT. Сам не тестив, репозиторій свіжий — але на HN 333 бали, і претензія до голосу Claude там явно резонує. Нюанс: це залежність від чужого CLI і ще одного акаунта Google, тож ставити варто усвідомлено.

## 📌 Рухи й безпека

**Команда MCP [виклала новий roadmap](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/) — п'ять напрямів після липневого релізу специфікації**

Що планують:
• **agentic messaging** — вихід за межі request-response: розширення Tasks (SEP-2663) дозріває, щоб переїхати в саму специфікацію; subscriptions/listen і progress notifications перевіряють на сумісність між робочими групами
• **один транспорт** — Streamable HTTP скрізь, включно з локальними серверами, які говоритимуть ним поверх stdio
• **ідентичність агента** — DPoP і Workload Identity Federation, щоб хмарний агент автентифікувався без API-ключів
• **progressive discovery** — сервер віддає маленький вхідний набір тулів і розкриває каталог по ходу розмови
• **SDK** — ергономіка і відповідність специфікації

Конкретних дат і версій у пості немає, лише напрямки і два SEP-номери (2663 для Tasks, 2133 для Extensions).

Найцікавіше тут — progressive discovery: саме роздутий каталог тулів зараз зʼїдає контекст, коли підключаєш кілька MCP-серверів одразу. Але це поки план, а не реліз.
