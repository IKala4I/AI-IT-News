## 🚀 Моделі

**[CLM-8B](https://github.com/Contrastive-LM/CLM) — модель під Apache-2.0, яка нічого не генерує, а ранжує варіанти, і робить це до 9× швидше за Jev**

Всередині — заморожений енкодер Qwen3-8B і дві маленькі проєкційні голови; сама голова важить 75 MB. Тренували трьома етапами: ~60M Q&amp;A-пар Nemotron, ~30M синтетичних hard negatives, ~1M агентних траєкторій.

Що обіцяють:
• zero-shot тримає рівень Jev на computer-use, іграх і tool-calling — при до 9× нижчій латентності
• з донавчанням: 87.6% на Terminal-Bench 2.1 і 81.6% на DeepSWE, у 4–6× швидше за Jev

Ваги [на Hugging Face](https://huggingface.co/Contrastive-LM/CLM-v0.1-8B), теж Apache-2.0. Треба Python 3.10+, Linux і NVIDIA GPU:

```bash
git clone https://github.com/Contrastive-LM/CLM.git && cd CLM
pip install -r requirements.txt
# далі підняти енкодер через vLLM (прапорці в README), потім:
clm-serve --port 8700 --emb-url http://127.0.0.1:8090/v1/embeddings
```

Якщо в пайплайні є місце, де модель просто обирає з кількох варіантів або ставить оцінку — тягнути туди генеративну модель дорого й повільно. Ось саме під це.

**Liquid AI [виклали LFM2.5-VL-3B-DSpark](https://huggingface.co/blog/LiquidAI/lfm2-5-vl-dspark) — драфт на 280M, який розганяє їхню VL-модель у 2–3 рази**

Це не нова модель, а додаток до LFM2.5-VL-3B: маленька голова (+8.9% до розміру) вгадує наступні токени, велика лише перевіряє. Декодування — до 3.13× швидше на M5 Max і до 2.66× на H100; end-to-end виходить 1.56–2.62× і 1.64–2.27× відповідно.

Є і safetensors, і GGUF. Найкоротший старт — через MLX:

```bash
mlx_vlm.server --model LiquidAI/LFM2.5-VL-3B \
  --draft-model LiquidAI/LFM2.5-VL-3B-DSpark
```

Для SGLang і llama.cpp в анонсі є свої команди (там це `--speculative-algorithm DSPARK` і `--spec-type draft-dspark`).

Цікаво передусім тим, хто ганяє VL-модель локально на маці: швидкість росте без переходу на більшу модель і без квантизації.

## 🛠️ Інструменти

**Claude Code cloud sessions [вийшли з research preview](https://code.claude.com/docs/en/claude-code-on-the-web) — і роздають одноразовий кредит на спробу**

Хмарна сесія — це Claude Code, що крутиться на інфрі Anthropic: закрив ноут, а робота йде далі, стежити можна з браузера чи телефона. Доступно на Pro, Max і Team, а на Enterprise — з premium-сітами або Chat + Claude Code.

Окремої плати за хмарну VM немає, сесії їдять ті самі ліміти акаунта. Разовий кредит на спробу — \$100 на Pro і \$250 на Max — анонсували [в пості ClaudeDevs](https://x.com/ClaudeDevs/status/2102871550974427462); забрати треба до 7 жовтня.

Найкорисніше тут не «хмара заради хмари», а те, що довга задача більше не тримає відкритим термінал.

**Cursor [додав двох ботів на останню милю](https://cursor.com/blog/rollouts-and-security-reviewer) — Rollouts стежить за деплоєм, Security Review шукає діри в PR**

Rollouts чіпляється до PR ще до мержу: читає дифф і системи, яких той торкається, лишає план моніторингу коментарем, а після деплою порівнює метрики з базовою лінією і каже одне з трьох — verified healthy, regression detected або inconclusive. Вміє читати Datadog, Grafana і Honeycomb.

Security Review йде по потоку даних від входу користувача: інʼєкції (SQL, command, template, LDAP), авторизація на нових роутах, закомічені секрети, небезпечна десеріалізація, незахищені редиректи. До кожної знахідки — severity, шлях атаки і фікс у один клік.

Обидва на Teams і Enterprise, вмикаються на вкладці automations у cursor.com/automations.

Цікава не сама перевірка, а те, що бот дивиться на зміну вже після деплою — це та частина, яку зазвичай ніхто не автоматизує.

**Claude Code [у 2.1.281](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) навчив MCP просити браузерний логін, а `/insights` — радити auto mode**

З помітного:
• MCP URL-mode elicitation: сервер може попросити відкрити браузер, щоб ти залогінився
• `/insights` дивиться на твої недавні промпти дозволів і радить, чи вмикати auto mode
• `claude plugin validate` перевіряє сервери на неоголошені конфіг-посилання й небезпечні URL
• полагодили обробку небезпечних `rm` в auto mode і в skip-permissions
• скролбари в `/skills`, `/mcp` і `/plugin` у фулскрині, плюс купа фіксів резюмування сесій і кеша промптів

Фікс `rm` — найпрактичніше: саме в auto mode ти цю команду очима вже не ловиш.

## 💡 Рецепти

**Рецепт: [ганяти кілька хмарних сесій Claude Code просто з термінала](https://code.claude.com/docs/en/claude-code-on-the-web)**

План збираєш локально, виконання віддаєш у хмару:

```bash
claude --permission-mode plan      # зібрати план і закомітити його в репо
claude --cloud "Execute the migration plan in docs/migration-plan.md"
```

Кожен `--cloud` — окрема незалежна сесія, тож дрібні задачі можна пускати пачкою:

```bash
claude --cloud "Fix the flaky test in auth.spec.ts"
claude --cloud "Update the API documentation"
```

Дописати вже запущеній сесії можна з будь-якої машини, де ти залогінений — команда кладе одне повідомлення в чергу і виходить:

```bash
claude -p "додай тест на порожній масив" --cloud session_01DiUkqY2kzbUbDmW1w96rfi
```

Забрати роботу назад у термінал — `claude --teleport` (інтерактивний пікер) або `/tp` усередині сесії.

Одна пастка: хмарна VM клонує GitHub-ремоут на поточній гілці, а не твій локальний чекаут. Не запушив — сесія працюватиме зі старим кодом.

Офіційна фіча, всі команди взяті з документації Claude Code.
