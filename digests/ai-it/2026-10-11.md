**Qwen [виклали Qwen-Image-2.1-Turbo](https://huggingface.co/Qwen/Qwen-Image-2.1-Turbo) — та сама 7B-архітектура, але 8 кроків денойзингу замість повного семплінгу**

Розклад на 8 кроків зашитий у чекпоінт і підхоплюється сам. Крутити `num_inference_steps` марно: щоб змінити розклад, треба передавати `sigmas` руками, а інші розклади під цей чекпоінт не перевіряли.

Потрібен Diffusers з майстра:

```
pip install git+https://github.com/huggingface/diffusers.git
pip install "transformers>=5.17.0" accelerate pillow
```

```python
from diffusers import QwenImage21Pipeline

pipe = QwenImage21Pipeline.from_pretrained(
    "Qwen/Qwen-Image-2.1-Turbo", dtype=torch.bfloat16,
).to("cuda")
```

Дефолт — CFG=1 і prefix KV-кеш. Вміє і text-to-image, і редагування картинок.

Ліцензія — Qwen Research License, тож у продукт так просто не візьмеш. Але для локальної генерації ассетів чи швидких прототипів 8 кроків — це інша швидкість ітерації.

**Cockroach Labs [п'ять місяців катали продакшн-код через пайплайн агентів](https://www.cockroachlabs.com/blog/experiment-running-hospital-code/), зібраний за моделлю клінічної лікарні**

Ролі: Fellow планує і пише, Review Attending — окремий інстанс — шукає дефекти і може відхилити план, Discharge Nurse перед мержем аудитує сам запис рев'ю, Charge Nurse раз на 30 хвилин перезапускає зависле. Все на GitHub Actions: стадія тригериться лейблом на ішʼю і закінчується новим лейблом.

Жорсткі правила живуть у скіл-файлах: ніякого коду без затвердженого плану; тести не можна вимикати чи послаблювати, а новий тест має падати без фікса; після чотирьох раундів переробки з новими блокерами PR летить до Attending.

Цифри за п'ять місяців: 1238 змержених PR, понад мільйон рядків, 7 ревертів, трохи більше \$135 000 — близько \$84 за ішʼю.

Навіть без двадцяти агентів звідси можна забрати дві речі: лейбли як стейт-машину і правило «тест має падати без фікса».

## 💡 Рецепти

**Рецепт: [компактити Claude Code вдвічі раніше](https://code.claude.com/docs/en/model-config), ніж він хоче сам**

У проєкті з декомпіляцією вище поріг компакшену опустили з 90% до 42%: автор пише, що агент у напханому контексті починає тупити задовго до того, як контекст реально закінчиться.

Синтаксис офіційний. Для моделі з 1M вікном 42% — це 420K:

```
/autocompact 420k                                # поточна модель, лягає в modelSettings
claude --autocompact 420k                        # на один запуск, не чіпає налаштування
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=420000    # у скриптах і CI, б'є все інше
```

Або одразу для всіх моделей у `~/.claude/settings.json`:

```json
{ "autoCompactWindow": 420000 }
```

Приймає від 100K до 1M токенів у будь-якій формі: `200000`, `500k`, `1M` або просто `200` (= 200 тисяч). Відсотків не розуміє, тож на 200K-моделі найраніше, що можна поставити — `/autocompact 100k`. Назад до дефолту — `/autocompact auto`.

Поріг 42% — з трьохмісячного проєкту вище, синтаксис — з офіційної документації Claude Code. Сам не тестив.
