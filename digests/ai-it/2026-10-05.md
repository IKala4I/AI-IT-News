## 🛠️ Інструменти

**Cloudflare [відкрили Web Search API](https://blog.cloudflare.com/introducing-web-search-api/) — один ендпоінт, щоб агент шукав у вебі замість вгадувати URL-и**

Три провайдери на вибір: `ceramic` (дефолт), `exa`, `linkup`. Повертає структуру — заголовок, URL, опис — яку можна одразу класти в контекст моделі. `limit` від 1 до 10, запит до 1024 символів.

Їде через AI Gateway, тож логи, аналітика і білінг ті самі, що й на інференсі. Платиш за прайсом провайдера «without any additional markup», або підсовуєш свій ключ через BYOK.

```bash
curl https://api.cloudflare.com/client/v4/accounts/$CLOUDFLARE_ACCOUNT_ID/ai/websearch/ \
  --request POST \
  --header "Authorization: Bearer $CLOUDFLARE_API_TOKEN" \
  --header "Content-Type: application/json" \
  --data '{
    "query": "What are some fun things to do in Salt Lake City as fall approaches?",
    "provider": "exa",
    "limit": 5,
    "options": { "gateway": { "id": "default" } }
  }'
```

У Workers те саме через біндинг: `env.AI.websearch({ gatewayId, query, provider, limit })`.

Поки beta, але якщо ти вже на Workers — це найкоротший шлях прикрутити пошук до свого агента: без окремого акаунта в Exa і без окремого білінгу.

**[Gitframes](https://github.com/gatewai-dev/gitframes) — композитинг, motion graphics і 3D для відео з коду, одним npm-пакетом під Apache-2.0**

Рендерить нативно на GPU (Dawn/WebGPU/Vulkan), без headless-браузера. Node 22+. Що в коробці:
• 50+ WebGPU-шейдерів: Curves, Film Grain, 3D LUT, PBR Glass, Mesh Warp
• GPU-типографіка на Slug з After Effects-аніматорами
• 3D-сцена з камерами, мешами і скелетною анімацією
• ONNX-зір на пристрої: детекція обʼєктів, поза, сегментація, трекінг
• процедурне аудіо і рендер у MP4 з покадрово точним звуком

```bash
pnpm add gitframes
```

Під агентів є окремий плагін: `/plugin install gitframes` у Claude Code або `npx skills add gatewai-dev/gitframes` для решти.

Статус — beta, версія 2.0.2 від 5 жовтня, API ще можуть поїхати. Але якщо треба робити релізні кліпи чи демки фіч із коду, це виглядає чеснішою альтернативою ланцюжку «headless-браузер + ffmpeg».

## 💡 Рецепти

**Рецепт: мод [prompt-cache-control](https://raw.githubusercontent.com/davila7/claude-code-templates/main/cli-tool/components/mods/observability/prompt-cache-control/README.md) показує таймер промпт-кешу просто в Claude Code**

Ні в Claude Code, ні в Codex видимого таймера кешу немає. Мод додає смужку над промптом: скільки промпту віддав кеш, скільки записано, скільки пішло без кешу — за запит і за турн.

```bash
npx claude-code-templates@latest --mod observability/prompt-cache-control
claude
```

`/cache` відкриває панель: великий відлік часу життя кешу (зелений, жовтий під 40%, червоний на порозі), стек read/wrote/new за останній запит і таблиця по турнах.

TTL визначає за пріоритетом: опція `ttl` мода → env-змінні → settings-файли → тип акаунта. Виходить 5 хвилин або година. Далі ще й дивиться на реальний трафік і виправляє себе, якщо кеш живе довше, ніж передбачив.

Тости прилітають на порозі (дефолт 60 с) і потім за 10, 3, 2 і 1 секунду до згорання — тільки для промптів від 20k токенів.

Офіційного мода такого немає: це community-мод з репозиторію claude-code-templates, команда і поведінка — з його README. Сам не тестив, але автор репо окремо радить саме цей як той, що найбільше економить токени.

Корисно, якщо працюєш сесіями з перервами: видно, коли дешевше дописати зараз, а не через п'ять хвилин.

## 📌 Рухи й безпека

**Команда Codex [пообіцяла 28 днів поспіль](https://x.com/thsottiaux/status/2106845241357824205) щодня або випускати помітне покращення, або роздавати всім скидання лімітів**

Тібо Соттіо, який веде ChatGPT і Codex, написав дослівно: «Over the next 28 days, each day we'll either ship one thing that is a clear improvement and relevant for most codex/work users or ship a full reset.» Вікно — з 4 жовтня до 1 листопада.

Фокус звузили до чотирьох речей: спрощення продукту, більше корисної роботи на одиницю ліміту, проривні фічі й нові моделі. Full reset — це освіження пʼятигодинного і тижневого ліміту акаунта.

Поки що в changelog Codex CLI останній запис — 0.160.0 від 1 жовтня, тож перші «щоденні» апдейти ще мають там зʼявитись.

Якщо тримаєш обидві підписки — наступний місяць найцікавіший час мати Codex під рукою. Якщо ні, просто глянь changelog за тиждень: по ньому й буде видно, це був план чи пост.
