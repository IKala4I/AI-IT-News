## 🛠️ Інструменти

**Simon Willison [зарелізив LLM 0.32](https://simonwillison.net/2026/Aug/4/new-release-of-llm/) — сам називає це найбільшим релізом з моменту запуску проєкту**

Три речі, які змінюють щоденне юзання:
• reasoning-траси стрімляться в stderr прямо під час генерації; ховаються через `-R/--hide-reasoning`
• серверні тули провайдерів вмикаються флагом `-T` — деталі в рецепті нижче
• нова схема логів: повідомлення зберігаються один раз і адресуються по хешу контенту, як у git, тож довгі діалоги більше не дублюють всю історію в SQLite

Сирі відповіді провайдера лежать у `turns.response_json`, стиснуті через `condense-json` — ту саму бібліотеку, що була в дайджесті 2 серпня. `llm logs --json` розгортає їх назад.

Ще з корисного: `llm openai endpoint` ганяє промпти або лістить моделі на довільному OpenAI-сумісному ендпоінті без попереднього конфігу. Такі виклики не логуються.

Разом приїхав llm-anthropic 0.26 з `claude-opus-5`, `claude-sonnet-5` і `claude-fable-5`.

**Claude Code [оновився до 2.1.222](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) — ізоляція worktree більше не дірява**

Головне: worktree-ізольовані сесії та їхні субагенти могли запускати деструктивні git-команди проти головного чекауту. Тепер ізоляція діє на файлові правки і Bash у сесіях будь-якого типу.

Другий фікс тієї ж природи: PreToolUse-хуки з auto-allow обходили обмеження тулів у бекграунд-задачах агента — резюме, компакція, перейменування.

Ще з релізу:
• `SendMessage` до інших агентських сесій тепер проходить через класифікатор дозволів в auto mode
• Remote Control більше не можна ввімкнути з репозиторних `.claude/settings.json` — тільки вимкнути; вмикається через `/config` на рівні юзера
• `/usage` перестав вішати на MCP-сервер усі ходи після першого виклику до нього
• ultraplan прибрали

Якщо ганяєш субагентів у worktree — це апдейт на сьогодні, не на «колись потім».

**Cloudflare [виклали Cloudflare OS](https://blog.cloudflare.com/cloudflare-os/) — опенсорсну платформу для агентів, яку можна підняти локально або в свій акаунт**

Ідея: агентський воркспейс із контекстом і скілами компанії плюс ізольований рантайм, де агент пише і запускає код. Застосунки називаються Gadgets — TypeScript, стан у SQLite, живуть у Dynamic Workers і Durable Objects.

Що всередині:
• Gatekeepers — capability-модель, агент не отримує креденшели напряму
• MCP Server Portals — підключення наявних MCP-серверів
• Cap'n Web — їхній опенсорсний object-capability RPC
• AI Gateway для вибору моделі й контролю витрат

Локально:

```bash
pnpm run-local
# http://localhost:8787
```

Apache-2.0, 1.2k зірок. Автори самі пишуть, що це early access у стані heavy development і «з багатьма гострими кутами».

![Cloudflare OS](https://blog.cloudflare.com/_emdash/api/media/file/01KZ7PN06AYFEQJN4FBVAE8WHH.png)

Цікаво не як готовий продукт, а як референс: рідкісний випадок, коли повний код «як гейтити агенту доступ до внутрішніх систем» просто лежить відкритий.

## 💡 Рецепти

**Серверні тули провайдера прямо з CLI — [через `-T` у LLM 0.32](https://llm.datasette.io/en/stable/openai-models.html)**

Веб-пошук і виконання коду більше не треба обв'язувати самому. І OpenAI, і Anthropic хостять ці тули у себе, а `llm` просто вмикає їх флагом — жодного MCP-сервера піднімати не треба.

OpenAI:

```bash
llm -m gpt-5.6-luna -T WebSearch 'Search the web for a positive news story from today'
llm -m gpt-5.6-luna -T 'CodeInterpreter(memory_limit="4g")' 'Run this calculation'
```

llm-anthropic 0.26 приносить той самий флаг для чотирьох тулів: `WebSearch`, `WebFetch`, `CodeExecution`, `AnthropicMCP`. Старі опції `-o web_search*` задепрекейчені на користь `-T WebSearch`.

Заразом там же змінилось керування thinking: тепер це `thinking` і `thinking_effort` зі значеннями `low`, `medium`, `high`, `xhigh`, `max`. У моделей Claude 5 thinking увімкнений за замовчуванням, вимикається через `-o thinking 0`.

Команди — з офіційної документації LLM і релізноутів llm-anthropic 0.26, сам не ганяв.

Найзручніше тут те, що пісочниця для коду і пошук уже на боці провайдера: платиш за них тими самими токенами і нічого не хостиш.
