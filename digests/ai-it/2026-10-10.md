## 🚀 Моделі

**Microsoft [зарелізили Decision-1](https://commandline.microsoft.com/microsoft-decision-1-model-foundry/) — модель не для тексту, а для рішень: \$0.042 за мільйон вхідних токенів і безкоштовний вихід**

Дотренували Qwen3.5-9B на один прохід скорингу. На фіксований набір варіантів віддає калібрований probability score і вміє:
• yes/no
• multiple-choice
• рейтинг за шкалою
• оцінку за рубрикою

Мірялись на 36 бенчмарках (~150K питань, усі held out): заявляють перше місце по точності, ~2.5x швидше за H2O-Lightning-4B v1.1 і ~35x швидше за GPT-6 Sol на P50. Внутрішні цифри — XBOX Research бачив якість близько до GPT-6 Sol при 14x швидкості, Copilot-команда — рівень GPT5.6 Luna при 100x. Обіцяють перезібрати на MAI і моделях OpenAI.

Є у [Foundry](https://ai.azure.com/catalog/models/Microsoft-Decision-1) і на [OpenRouter](https://openrouter.ai/microsoft/microsoft-decision-1).

Четвертий decision-ендпоінт за тиждень після OpenAI, Liquid AI і Ollama. Схоже, роутинг і класифікація остаточно переїжджають з великих моделей у дешеві спеціалізовані — для агента, що на кожному кроці вибирає тул, різниця в два порядки ціни відчутна.

## 🛠️ Інструменти

**Claude Code [у 2.1.296](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) дає субагенту компактитись раніше за головну сесію і вчить Read брати великі файли одним заходом**

• `autoCompactWindow` у frontmatter субагента і в `--agents` — власне вікно автокомпакту, окреме від головної сесії
• `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` — посадити всі workflow-агенти на одну модель, решта субагентів лишається як була
• `allow_large` у Read — прочитати текстовий файл понад звичайні ліміти, коли в контексті є місце
• `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` — довша максимальна пауза в backoff на 529

З фіксів два варті уваги: Edit і NotebookEdit більше не перетирають усі не-ASCII символи у файлах, що не є валідним UTF-8 (Windows-1252, Shift-JIS, GBK) — такі правки тепер просто відхиляються. А Bash перестав автоапрувити команди, які присвоюють `BASH_ARGV0` і потім його запускають.

Дві нові ручки — окрема модель для workflow-агентів і раннє компактування субагентів — про одне й те саме: щоб фан-аут не виїдав ліміти.

**Prime Intellect [переписали Prime Agent на Rust](https://www.primeintellect.ai/blog/prime-agent-rust) — холодний старт з 737.8 мс до 55.8 мс**

Їхні цифри, TypeScript → Rust:
• time to type, cold: 737.8 мс → 55.8 мс
• warm: 549.6 мс → 42.4 мс
• розмір встановленого: 172.1 МБ → 59.6 МБ
• RSS після старту: 607.4 МБ → 106.0 МБ

Порт зробили самі агенти за два тижні, люди переважно налаштовували верифікацію. Код розʼїхався на девʼять крейтів, найбільший файл схуд з ~15 000 рядків до ~2 500. Побічно зʼявилась бета під Windows і ізоляція крешів на кожну сесію.

```bash
curl -fsSL https://app.primeintellect.ai/prime-agent/install.sh | sh
```

Автори самі пишуть, що зовнішні порівняння робили власним набором тестів, тож до цифр варто ставитись сторожко. Але 600 МБ RSS проти 100 МБ видно одразу, коли тримаєш відкритими три сесії агента.

**[Talorys](https://github.com/rociiu/talorys) — персональний AI-агент, який розгортається у твоєму Cloudflare однією командою і живе на безкоштовному плані**

```bash
npx create-talorys@latest
```

Стрімінг-чат з Markdown, памʼять про факти й преференції (видно, можна правити й видаляти), таски, нотатки, проєкти, разові та повторювані ремайндери на Durable Object alarms, бекап і імпорт.

Під капотом Workers, Pages, Durable Objects на SQLite і Workers AI з `@cf/zai-org/glm-4.7-flash`, зверху Agents SDK і Hono, спереду React + Vite + TS. MIT, Node 20.18+. Single-user, без реєстрації: коли денна квота Workers AI закінчується, чат стає на паузу, а таски й нотатки працюють далі.

Цікаве тим, що в автора не хоститься нічого — свій акаунт, свої дані, нуль підписок. Вийшло сьогодні (`create-talorys` 0.1.2 опубліковано вдень), тож очікувано сире.

## 💡 Рецепти

**Рецепт: [REA](https://rea.tools/) підключає реверс-інжиніринг як MCP до Claude Code, Codex чи Cursor — однією командою**

```bash
npx rea-agents setup
```

Setup питає, які агенти підключати, показує пропоновані зміни конфігів (з бекапами) і ставить скіл з інструкціями під воркфлоу. Після рестарту агента він сам ходить по нативних бінарниках, JS/Electron-застосунках, .NET, APK, HAR-дампах і прошивках.

Те саме з терміналу, без агента:

```bash
npx -y rea-agents@latest analyze-javascript-application /absolute/path/to/app --json
```

Потрібен Node 22.19+, 24.11+ або 26+. Для нативних бінарників — Hopper, Ghidra або IDA (setup може поставити Hopper після підтвердження), статичний аналіз JavaScript працює без жодного движка.

Команди з README, MIT, у npm `rea-agents` 6.3.0 від сьогодні; сам не тестив, але на HN за добу ~590 апвоутів.

Для мобільщика найцікавіше не бінарники, а `analyze-javascript-application` по ASAR: подивитись, як конкурент зробив фічу, і отримати не здогадку, а посилання на конкретний модуль з доказами.

## 📌 Рухи й безпека

**У Telegram Desktop [тихо залатали one-click викрадення акаунта](https://beaksec.github.io/posts/telegram-desktop-one-click-account-takeover/) — CVE-2026-107181, 8.1 High, фікс у 7.2.9**

Single-instance IPC не екранував символ, яким розділяє команди, тож крафчене `tg://`-посилання давало доінжектити свої. Одна з них — внутрішня схема `interpret:` — читала названий файл і відправляла його в чат, не перевіряючи, хто просив, і без підтвердження. Разом це довільне читання локальних файлів: автор витяг session-файли і зайшов в акаунт.

Для атаки треба один клік по посиланню, спільний груповий чат з атакером (дефолтні налаштування дозволяють додати тебе без згоди), автозавантаження групових файлів до 8 МіБ у передбачуване місце і відсутність локального passcode. Жодного коду на машині заздалегідь.

Вразливі версії включно з 7.2.8, фікс у 7.2.9 (коміт `db3405699f`) — без адвізорі, у ченджлозі згадали лише рендеринг.

Перевір версію і постав passcode: без нього вкрадених файлів достатньо, щоб розшифрувати сесію.
