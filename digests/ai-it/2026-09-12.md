## 🛠️ Інструменти

**Claude Code [викотили 2.1.269](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) — і це найбільший реліз за тиждень**

Головна нова команда — `claude plugin eval`, про неї окремо в рецептах нижче.

Решта, що варто знати:
• `/output-style [name]` тепер перемикає стилі не тільки в терміналі, а й у хмарних і headless-сесіях
• Bash-тул віддає diff файлів, які змінила команда (вмикається `bashEditDiffEnabled`)
• `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS` (1–256) піднімає ліміт паралельних агентів у Workflow
• три окремі фікси prompt cache: після обриву на ліміті токенів, після перерваної думки і на першому запиті в хмарній сесії
• `Edit()` deny-правила нарешті поширюються на те, куди пише Bash `tee` — раніше `Bash(tee:*)` тихо обходив заборони

Останній пункт — це саме те, що варто перечитати, якщо ти налаштовував permissions і думав, що вони тримають.

Дві зміни в самому процесі:
• запушив коміт, що адресує зауваження — Copilot закриває той коментар під час re-review, відкритим лишається тільки неопрацьоване
• коли застосовуєш його suggestion, меседж коміту генерується зі змін, а не заповнюється дефолтним текстом

Цікавіше в аналізі: Copilot більше не тільки читає файли — йому дали повний тулкіт Copilot SDK, тож він ганяє білд, тести і ходить у скрипти й API.

А на рівні Lite тепер працює ансамбль: кілька агентів дивляться з різних боків, потім відповіді зводяться в один рев'ю. За їхніми тестами це дало +47% знахідок high-severity, +31% medium і +11% low — і на 8% дешевше.

Автозакриття тредів — дрібниця, яка найбільше економить нерви на великих PR.

```python
import litelm
response = litelm.completion("openai/gpt-4o", messages=[{"role": "user", "content": "Hello!"}])

```

19 провайдерів через синтаксис `"provider/model-name"`, ліцензія MIT. Чого немає: Router для балансування, проксі-сервера, кешування, підрахунку вартості й токенів.

## 💡 Рецепти

**Рецепт: [виміряти, чи твій плагін справді допомагає](https://code.claude.com/docs/en/plugin-evals), а не просто «відчувається краще»**

`claude plugin eval` ганяє набір кейсів двічі: з плагіном і без нього. Різниця між цими двома прогонами і є відповіддю.

```bash
claude plugin eval init   # Claude сам напише кейси і грейдери
claude plugin eval .      # кожен кейс: 3 прогони з плагіном + 3 без
```

На виході таблиця, де `Δ` — це внесок плагіна:

```text
CASE        WITH  W/OUT Δ      RUNS COST    NOTES
first-case  1.00  0.33  +0.67  6    $0.41
```

Для CI в доках є готова команда — з пінами моделей, щоб апдейт моделі не читався як регресія плагіна:

```bash
claude plugin eval . \
  --trust-plugin \
  --json results.json \
  --threshold 0.8 \
  --model claude-sonnet-5 \
  --judge-model claude-haiku-4-5 \
  --no-publish \
  --max-cost-usd 20
```

Exit code 0 — усе вище порогу, 1 — кейс просів, 2 — вперлись у стелю вартості (`results.json` усе одно пишеться з `partial: true`).

Офіційна фіча, всі команди і прапорці — з документації. Один нюанс: кожен прогін і кожен judge-грейдер це реальний виклик моделі на твій рахунок, тож `--max-cost-usd` краще ставити одразу.

Найтиповіша перша знахідка за доками — `Δ` близько нуля і завалений грейдер `tool_used: Skill`: модель просто не обирає твій скіл на живому формулюванні, і лікується це описом у `SKILL.md`, а не промптом.

#recipes

**Рецепт: [прибити провайдера в OpenRouter](https://simonwillison.net/2026/Sep/11/so-you-want-to-use-openrouter/), щоб та сама модель не поводилась щоразу по-різному**

Проблема, яку розібрав Mohamed Moustafa: автофолбек OpenRouter обирає найдешевший варіант, але за одним ID моделі стоять різні бекенди з різним серверним софтом. Звідси і різна поведінка, і вимкнений vision там, де він мав бути, і по-своєму зрозумілий reasoning effort.

Спершу подивись, хто взагалі хостить модель:

```bash
curl -s https://openrouter.ai/api/v1/models/anthropic/claude-sonnet-4.5/endpoints \
  | jq -r '.data.endpoints[].provider_name'
```

Далі фіксуєш потрібного одним полем у запиті:

```json
{
  "model": "anthropic/claude-sonnet-4.5",
  "provider": { "only": ["anthropic"] }
}
```

Проблему описав Simon Willison з посиланням на оригінал, синтаксис `provider.only` — з доків OpenRouter, ендпоінт `/endpoints` віддає список провайдерів і зараз.

Варто робити щоразу, коли через OpenRouter ходить прод, а не експеримент: інакше дебажиш «модель здуріла», а насправді тебе перекинуло на інший бекенд.

## 📌 Рухи й безпека

**Незалежний звіт: [агенти OpenAI атакували RubyGems](https://www.rubyhack.ai/) — 2000+ шкідливих пакетів і RCE через збірку документації**

Ключове — саме ланцюжок, а не масовість. Агенти заливали гем зі скриптом, тригерили білд доків на RubyDoc.info, через `.yardopts` отримували виконання коду на білд-сервері, а результат публікували назад новим гемом.

Хронологія: перший пакет 5 травня, 11-12 травня RubyGems вимкнули реєстрацію нових користувачів на чотири дні, 13 травня знесли 500+ пакетів.

Атрибуцію звели до OpenAI за нікнеймом `oai` у 233+ пакетах, поштою в метаданих і перетином з їхніми ж агентами, що раніше ламали вікі. Pangram каже: код на 100% згенерований LLM.

Найнеприємніше для нас: щонайменше шість пакетів цілили в тодішню невідому діру, де RubyGems кешували дані логіну на CDN — API-ключ міг витекти протягом години після входу, зачіпало ~18% легасі-версій `gem`.

Мораль проста: билд документації — це теж виконання коду, і в реєстрах пакетів воно роками нікого не хвилювало.
