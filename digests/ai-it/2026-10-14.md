## 🚀 Моделі

**Subquadratic [виклали SubQ Snap](https://subq.ai/introducing-subq-snap) — модель для рішень, яка не генерує текст, а віддає ймовірність по фіксованому списку дозволених відповідей**

Рахована під точки рішень в агентному лупі: роутинг, вибір тула, перевірка результату, зупинка. Довгий вхід читає через Subquadratic Sparse Attention, авторегресії немає зовсім.

• 384K токенів тексту і картинок в одному виклику
• ~1 секунда на вході близько 100K
• \$0.05 за Mtok входу, згенерований вихід не тарифікується

Проти Jev: Decision LCR 74.0 проти 48.0 (Jev ріже вхід на чанки), Bespoke Nimble 82.9% проти 76.0%, Decision RULER тримає 96.3-99.8 від 32K до 1M. Цифри свої, незалежних прогонів поки немає.

Public preview видають за принципом хто перший — як скінчиться капасіті, нових ставлять у вейтліст.

Якщо в тебе агент тягне Opus чи Sol на «який з цих 40 файлів релевантний» — ось рівно та задача, яку таке закриває за копійки.

## 🛠️ Інструменти

**Claude Code [у 2.1.299](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) сам компактить сесію, яку ти покинув — поки не згорів прогрітий кеш**

Сесія на 200K+ токенів, яку лишили в простої приблизно на 54 хвилини, компактиться до того, як спливе її годинний prompt cache. Наступне повідомлення вже не переганяє все заново.

Крутилки: `CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` зсуває поріг у 200K, `"idleCompaction": false` у settings.json вимикає взагалі. Обидві потребують 2.1.290 або новіше.

Там же `CLAUDE_CODE_DISABLE_FILE_MENTIONS`: `@`-згадки приїжджають як шляхи, які Claude читає сам, а не як вміст файлу в промпті.

З 2.1.296, якщо пропустив: `autoCompactWindow` у фронтматері субагента (компактить раніше за головну сесію), `allow_large` у Read, і `/cost` зі статус-лайном тепер рахують cache read Sonnet 5.5 по \$0.10 за Mtok замість \$0.20.

Перші дві змінні — це прямий мінус до спалених токенів на довгих сесіях, без зміни звичок.

**[Graphicle](https://github.com/graphicle-ai/graphicle) — код-граф і памʼять репозиторію в одній Rust-бінарці, що сама себе підключає до агентів через MCP**

`graphicle setup` індексує репо, будує граф і конектить усі знайдені клієнти: Claude Code (`.mcp.json`), Codex (`~/.codex/config.toml`), Cursor, VS Code, Claude Desktop. Додає секцію в `AGENTS.md`, вмикає запис сесій і ставить git-хуки. Кожен змінений файл бекапить, `graphicle disconnect` відкочує все.

Памʼять — це не історія чату: доки (Markdown, PDF, Office, HTML), ухвалені рішення і минулі сесії Claude Code та Codex. Записи привʼязані до функцій і позначаються застарілими, коли той код змінився.

Apache-2.0, macOS і Linux, нативного Windows поки немає. Бенчмарки свої: Kubernetes (~31k файлів) за 3 хв 18 с проти 26 хв 38 с у Graphify, один прогін.

Ідея та сама, що в Pensieve два дні тому, але тут ще й памʼять зі staleness. Дивись на дату: 2 коміти в `main`, тож ставити варто на тестовому репо, а не на робочому.

## 💡 Рецепти

**Рецепт: [крутити клаудні моделі Ollama всередині Fly.io Sprites](https://ollama.com/blog/fly-io-sprites) — так, щоб агент у пісочниці не бачив твого API-ключа**

Sprite — повноцінна Linux VM із власним диском, що лишається між сесіями; Claude Code, Codex і Gemini CLI підтримуються з коробки. Ключ Ollama лежить в організації Fly.io, запит іде через їхній гейтвей, який сам додає авторизацію. Пісочниця знає лише URL і connection ID, тож злити ключ з неї нічим.

У дашборді Fly.io: Sprites → Connectors → додати конектор Ollama, далі в Access Configuration вибрати, кому можна. Нові конектори за дефолтом блокують усі Sprites — доступ даєш за лейблом, префіксом імені або всім.

Зсередини Sprite:

```
curl "https://api.sprites.dev/v1/gateway/ollama/<connection_id>/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{"model": "kimi-k3", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Python — будь-який OpenAI SDK, `api_key` можна будь-який:

```python
from openai import OpenAI
client = OpenAI(
    base_url="https://api.sprites.dev/v1/gateway/ollama/<connection_id>/v1",
    api_key="unused",
)
```

Доступні `kimi-k3`, `glm-5.3`, `deepseek-v4.1-flash`. Нативні роути `/api/*` теж ходять через гейтвей.

Офіційна фіча, команди один в один з анонсу Ollama; сам не тестив. Корисно рівно тоді, коли агенту треба дати `--dangerously-skip-permissions` і при цьому не дати доступ до своїх секретів.
