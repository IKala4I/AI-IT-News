## 📌 Важливо знати

**У маркетплейсі Cursor [майже 11 годин лежало розширення Claude Code 2.1.313 з бекдором](https://cursor.com/blog/claude-code-extension-security-notice): воно додає чужий SSH-ключ на твій комп'ютер і відправляє нападнику дані про систему**

Це було в четвер, 29 жовтня, приблизно з 11:27 до 22:35 за Києвом. Зачепило до 5 000 юзерів Cursor. За словами Anthropic [на HN](https://news.ycombinator.com/item?id=50300683), звичайний VS Code і Open VSX чисті.

Перевір свій Mac:

```
grep -qs svc-telemetry ~/.ssh/authorized_keys && echo "svc-telemetry key found" || echo "No key found; machine not impacted"
```

Якщо ключ знайшовся, видалити розширення замало. Запусти скрипт очистки з поста Cursor і зміни токени, до яких є доступ з цього Mac.

**OpenAI тепер [щомісяця дає підписникам ChatGPT Pro кредити на API](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) на суму підписки: \$100, \$200 або \$500**

• забрати: ChatGPT → Settings → Billing, далі обираєш свою API-організацію
• підписці має бути щонайменше 7 днів, а email у ChatGPT і в API має збігатися
• залишок згорає в кінці місяця, ліміти Codex від цього не ростуть, а Codex через API-ключ кредити не покривають

[Simon Willison](https://simonwillison.net/2026/Oct/29/api-credits/) називає це майже точною копією жовтневої схеми Anthropic для Max і Team. Якщо платиш за Pro, натисни кнопку зараз: перший місяць рахують пропорційно, а пет-проєкти на API підуть без окремого білінгу.

## ✨ Цікавинка

**У Y Combinator [запустили 50 агентів на GPT-6.1 Sol у Minecraft](https://labs.ycombinator.com/projects/games/index.html) з одним завданням «побудуйте процвітаючу цивілізацію», і за три години вони вигадали собі бюрократію.** Агенти завели журнал пайків, писані правила й дозволи, а четверо з них 11 хвилин призначали «єдиного оператора добрив» заради однієї порції кісткового борошна. Лідером без жодних виборів став агент, який просто стояв першим у списку, і йому прийшло 616 особистих повідомлень. В іншій грі, Mindustry, команда GPT-6.1 Sol у Codex обіграла команду Claude Opus 5.5 у Claude Code з рахунком 6:1, і агенти GPT самі полізли читати вихідний код гри, а агенти Claude цього жодного разу не зробили.
