**Anthropic [скасували підняття ціни на Claude Sonnet 5](https://platform.claude.com/docs/en/release-notes/api) — \$2/\$10 за мільйон токенів стали стандартним тарифом**

Вступна ціна мала вирости до \$3/\$15 з 1 вересня. У релізноутах платформи від 10 серпня написали коротко: підняття не відбудеться, поточний тариф тепер і є звичайним.

Ніяких умов, вейтлістів чи «для перших N клієнтів» — просто скасували заплановане.

Sonnet 5 і так тягнув більшість агентних задач за розумні гроші. Тепер аргумент «а може, перевести пайплайн на щось дешевше до вересня» відпав сам собою — якщо ти вже почав такий переїзд, є сенс зупинитись і перерахувати.

**NVIDIA [зарелізили Nemotron 3.5 Lightning](https://ollama.com/blog/nemotron-3-5-lightning) — 30B з 3B активних і мільйоном токенів контексту, під локальних агентів**

Гібридна архітектура: Mamba-2 і MoE-шари плюс кілька attention-шарів. Ollama викотили модель у день релізу.

Що заявляють:
• 30B параметрів, 3B активних на токен
• контекст до 1M токенів
• MMLU Pro 81.62, SWE-bench Verified 52.80
• 4× throughput і на 30% швидше завершення задач проти інших відкритих моделей свого розміру
• ліцензія OpenMDW-1.1, дата релізу — 11 серпня

```bash
ollama run nemotron-3.5-lightning
ollama launch claude --model nemotron-3.5-lightning
```

Той самий `ollama launch`, що вчора з Muse Glimmer; на Apple Silicon є збірка `nemotron-3.5-lightning:30b-mlx`. NVFP4 розрахований на Blackwell і Hopper, для Ampere є W4A16.

52.8 на SWE-bench Verified — це помітно нижче за вчорашні 76% у Muse Glimmer. Але мільйон контексту при 3B активних параметрів — інший розмін: не «розумніша модель», а «модель, яка не задихається на довгій агентній сесії».

**Cactus [виклали Needle 2](https://cactuscompute.com/needle) — 45M-модель для tool calling, яка вміщається в 14MB і 28MB RAM**

Сьогодні це топ-1 AI-новина на HN (472 бали). Модель робить одну річ: текст на вході, JSON виклику тула на виході, а byte-level граматика з твоїх схем обмежує кожен токен.

Цифри:
• 45M параметрів, CQ2-бітна квантизація, один бінар на 14MB
• 500 tok/s на Raspberry Pi 5, 300-700 на бюджетних Android
• ваги під Apache 2.0, код під MIT
• ARM64, x86-64, ARMv7, RISC-V і WebAssembly

```bash
pip install cactus-needle
needle playground
```

Є tool retrieval: оголошуєш великий каталог тулів, вбудована retrieval-голова рендерить лише топ-5 на хід.

Порівняння з FunctionGemma 270M і LFM2.5 230M — від самих авторів. Але сам формат цікавий: роутер інтентів, який крутиться локально на пристрої і не ходить у мережу взагалі.

## 💡 Рецепти

**Віддай MCP-тули агенту компактніше — [`mcptoon`](https://github.com/activeing123/mcptoon) замість JSON у контексті**

Знайома проблема: підключив три MCP-сервери — і кілька тисяч токенів контексту з'їдені описами тулів ще до першого повідомлення. `mcptoon` — CLI-клієнт до MCP-серверів, який віддає не JSON, а компактну нотацію.

Ставиться і налаштовується так:

```bash
pip install mcptoon
mcptoon init
mcptoon add fetch --stdio npx -y @modelcontextprotocol/server-fetch
```

Далі агент викликає тули через CLI, а не через нативний MCP-транспорт:

```bash
mcptoon manifest --toon
mcptoon call fetch fetch '{"url":"https://example.com"}' --toon
```

Для Claude Code автори радять виставити тип агента і покласти команди в `SKILL.md`:

```bash
export MCPTOON_AGENT_TYPE=claude
```

Для Cursor — ті самі команди в `.cursorrules`.

Заявлена економія: 97% на дискаверингу тулів (10 000+ токенів проти 350), 40-60% на результатах викликів, 93% на схемах у режимі `--slim`. Ліцензія Apache 2.0.

Цифри — від автора, сам не ганяв, проєкт свіжий (сьогодні у Show HN). Але напрямок правильний: описи тулів — це податок, який ти платиш у кожному запиті, а не один раз.

## 📌 Рухи й безпека

**Зашифровані reasoning-блоки [виявились взаємозамінними між сесіями, юзерами і моделями](https://arxiv.org/abs/2608.09867) — і розшифровуються чужою моделлю того ж провайдера**

Провайдери ховають chain-of-thought: віддають клієнту зашифрований блок, який той повертає в наступному запиті. Автори показали, що ці блоки сумісні між різними сесіями, акаунтами і навіть моделями одного провайдера.

Звідси атака: підсовуєш reasoning від сильної моделі слабшій моделі того ж провайдера — і вона видає його відкритим текстом. Перевірено на Anthropic, OpenAI і Google.

Найнеприємніше не обхід анти-дистиляції, а другий результат: автори прогнали 315 320 блоків з публічних репозиторіїв і дістали 367 PII-артефактів та 182 креденшели. Тобто логи сесій, які люди спокійно комітять «бо вони ж зашифровані», насправді читаються.

Четвертий вектор — невидимі prompt injection всередині таких блоків.

Практичний висновок на сьогодні: пошукай у своїх репо збережені відповіді API з `thinking`-блоками. Зашифрований ≠ приватний.

**Anthropic [почали маркувати все, що генерує Claude](https://support.claude.com/en/articles/16266773-how-claude-marks-ai-generated-content) — включно з виводом Claude Code**

Довідкова стаття зібрала 354 бали на HN. Маркування діє для моделей, випущених з 2 серпня 2026, і працює скрізь: API, Claude, Claude Code, Cowork, Claude Tag — у всіх регіонах.

Дві техніки:
• непомітний вотермарк, вплетений у сам текст — переживає копіпаст і частину редагувань
• підписані C2PA-метадані для `.svg`, `.png`, `.jpg`

Про можливість вимкнути в статті не сказано нічого.

Anthropic самі уточнюють, що знайдена мітка означає лише «контент міг бути оброблений Claude» — модель могла просто відредагувати чужий текст. Зворотне теж вірно: відсутності мітки недостатньо, щоб щось довести.

Знати про це варто передусім через C2PA: картинки й SVG, які агент згенерував і ти закомітив, несуть підписані метадані про походження.
