**Claude Code [у 2.1.283](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) додав `/doctor prompt-audit` — аудит твоїх CLAUDE.md на патерни під старі моделі**

Команда проходить по CLAUDE.md і промптах і показує місця, написані під моделі, яких уже немає або які давно не дефолтні.

Ще з цього релізу:
• `availableModelsMatch: "exact"` — managed-настройка, що блокує нові релізи моделей, поки їх явно не додали в список
• `deniedModels` — забороняє конкретні моделі, навіть якщо `availableModels` їх дозволяє
• виводи MCP-тулів тепер летять в OpenTelemetry-спани при `OTEL_LOG_TOOL_CONTENT=1`

Якщо твій CLAUDE.md писався пів року тому і досі радить агенту «візьми модель X для Y» — є що почистити. Дві managed-настройки — це вже для тих, хто роздає Claude Code команді.

**[Drawgent](https://tangled.org/yanndegat.tngl.sh/drawgent) садить Claude Code, Codex або opencode на живий Excalidraw-канвас**

Агент отримує MCP-тули на полотно, скріншоти і scene data: малює, дивиться на результат, правує. Ти або просиш діаграму в чаті збоку, або пишеш прямо на канвасі нотатку `AGENT: ...` — і він її підхоплює.

```
drawgent setup claude   # перевіряє CLI, логін, ACP-бридж і Chrome
cd ~/my-repo
drawgent up             # підіймає сервер + агента і відкриває браузер
drawgent up --attach    # причепити канвас до вже запущеної сесії агента
```

Треба Node ≥ 22, Chrome і git-репозиторій як контекст. Сервер піднімається на `127.0.0.1:7300`.

Схоже на Whiteboard із позавчорашнього дайджесту, але навпаки: там агент звітує діаграмою, а тут ти ним малюєш.

**[Reladraw](https://github.com/reladraw/reladraw) — текстова мова для діаграм, де розташування задаєш ти, а не layout-енджин**

Mermaid і Graphviz самі вирішують, де що поставити; draw.io змушує тягати мишкою. Reladraw — середина: пишеш відносне розташування словами.

```
node app "Web app"
node store "Database"  right of app
edge app -> store  "queries"
```

Парсер, layout і SVG-рендер на TypeScript без залежностей. Apache-2.0, версія 0.8.0 — синтаксис автори самі називають нестабільним.

```
npm install -g reladraw
reladraw diagram.reladraw -o diagram.svg
npx skills add reladraw/reladraw -g   # щоб агент умів у цей синтаксис
```

Остання команда і є найцікавіша: агенту простіше згенерувати схему, коли розкладку можна описати словами, а не вгадувати, що зробить автолейаут.

## 💡 Рецепти

**Рецепт: [перетворити GLM-5.3-Flash у decision-модель](https://www.privatemode.ai/blog/system-one-from-glm-flash) без файнтюну — одним prefill'ом**

Ідея проста: не проси модель відповісти текстом, а змусь її першим же токеном видати індекс варіанта.

• пронумеруй опції в JSON
• prefill асистента рядком `choice_index:`
• забери logprobs з однієї позиції замість генерації

На vLLM це `allowed_token_ids`, `logprob_token_ids` і `continue_final_message` з `add_generation_prompt: false`. Бібліотека-обгортка під MIT:

```
pip install git+https://github.com/edgelesssys/privatemode-decisions
```

```python
from decisions import Choice, OpenAIClient, SystemOne

engine = SystemOne(OpenAIClient("http://localhost:8080/v1"), "glm-flash-latest")
result = engine.system_one(
    "A customer writes: I was charged twice for the same transfer.",
    {
        "team": Choice({
            "payments": "wrong or duplicate charges",
            "technical": "app and login problems",
        }, instructions="Which team should handle this?"),
    },
)
```

Сам не тестив. Автори міряють медіанний розрив із Jev у 0.7 п.п. (p=0.64) і 180 мс латенсі з Німеччини, але виходить дорожче: €62 проти €16 за мільйон рішень. Зате приймає картинки, чого Jev не вміє.

Корисно, якщо роутер чи класифікатор потрібен на своєму інференсі, а не на чужому API.

**Рецепт: [зняти відео з локальної HTML-сторінки](https://simonwillison.net/2026/Sep/26/kakapo-party/) — Claude Code сам напише Playwright-скрипт**

Simon Willison готував кейноут і йому треба було відео canvas-анімації. Замість екранного рекордера він дав Claude Code один промпт:

```
Make me a video of file:///Users/simon/Downloads/kakapo-party.html - you need
to load it in a browser and click on it a few times to get the confetti effect,
the video should be 15s long don't start clicking until 3s in make sure several
clicks are spread around the clickable area
```

На виході — Python-скрипт на Playwright: браузер 1280×720, десять кліків у заданих координатах з таймкодами від 3.0s до 13.2s, запис на 15 секунд.

▶ [Жива сторінка з анімацією](https://tools.simonwillison.net/kakapo-party)

Офіційної фічі тут немає, це просто промпт — але ідея робоча для будь-якого демо: детермінований клікер замість «перезніму ще разок».
