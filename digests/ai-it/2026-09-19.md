## 🚀 Моделі

**Convai [виклали Laya](https://huggingface.co/convaiinnovations/laya) — відкриту Apache-2.0 модель-рішення, сумісну з Jev, 421M і 33 мс на відповідь**

Нещодавно тут був TypeSafe Jev — модель, яка замість тексту віддає типізоване рішення з каліброваною впевненістю. Тепер є відкрита реалізація тієї ж ідеї, і вчора вона забрала другий рядок на HN.

Три чекпоінти:
• `laya` — ModernBERT-large, 421M, англійська, 512 токенів на питання
• `laya-multilingual` — mmBERT-base, 322M, 100+ мов, приблизно вдвічі швидша
• `laya-typed-decisions` — дотренована під бенчмарк typed-decisions

Числа з картки моделі: p50 32.8 мс на Tesla T4 проти 236-276 мс у Jev, 0.766 точності на typed-decisions проти 0.727, ECE 0.081. Пакет `laya` 0.3.3 доїхав на PyPI сьогодні вранці.

```bash
pip install "laya>=0.3.3"
```

▶ [Покрутити демо на HF](https://huggingface.co/spaces/convaiinnovations/laya-demo)

Якщо в пайплайні висить виклик фронтір-моделі на «обери одну з пʼяти категорій» — ось кандидат, що крутиться локально за десятки мілісекунд і віддає ймовірності, а не текст, який ще треба парсити.

## 🛠️ Інструменти

**Claude Code [у 2.1.277 навчився читати AGENTS.md](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) — і зробили це вбудованим плагіном, сорси якого лежать відкрито**

Якщо в папці немає CLAUDE.md, Claude Code бере AGENTS.md і вантажить його рівно там і так само, як вантажив би CLAUDE.md. На Bedrock, Vertex і Foundry поки не працює.

Цікавіше інше: це не хардкод у движку, а [мод `agents-md`](https://raw.githubusercontent.com/anthropics/claude-code/main/mods/README.md) — один із чотирьох, що їдуть усередині бінарника. Anthropic опублікували їхні сорси: крім `agents-md`, це `diff` (панель з незакоміченими змінами поруч із транскриптом), `telemetry` і `sec-default`.

Наступна версія 2.1.278 — про гроші: на Enterprise, Claude API, Bedrock, Vertex і Foundry класифікатор auto mode тепер [рахується на сервері й не тарифікується](https://code.claude.com/docs/en/auto-mode-classifier-billing). Якщо між тобою і API стоїть гейтвей, який ріже незнайомі поля запиту, прилетить нотіс — і біллінг лишиться старий. У `/status` зʼявився рядок `Auto mode server`.

Головне тут не сам AGENTS.md, а те, що частину движка винесли в плагіни з публічним кодом: тепер видно, як саме інструкції потрапляють у контекст, і це можна перевизначити.

#tools

**Moonshot [зарелізили Kimi Code Desktop](https://www.kimi.com/code/docs/en/kimi-code/whats-new.html) — той самий агент, що в CLI, але у вікні з вбудованим браузером**

• macOS (Apple Silicon та Intel) і Windows
• Goal mode тягне довгу ціль і ставиться на паузу, продовжується чи скасовується; plan mode спершу показує підхід і лише потім чіпає файли; довгі задачі йдуть у фон
• три режими дозволів: Always Ask / Ask When Needed / Never Ask
• браузер живе в правій панелі, таби привʼязані до сесії, контекст сторінки видно агенту; є анотація скріншотів, коментарі до виділеного тексту, `@`-згадки файлів і піпетка по елементах сторінки

Того ж дня вийшов CLI v2.0.0: `/desktop` (він же `/install-desktop`) і `kimi install-desktop` відкривають сторінку завантаження, а mermaid-блоки тепер малюються діаграмами прямо в терміналі — вимикається через `mermaid = "off"` у секції `[markdown]` файлу `tui.toml`.

Браузер у правій панелі з піпеткою по елементах — це саме той шматок циклу, якого зазвичай бракує: показати агенту, що саме зламалось, не описуючи це словами.

## 💡 Рецепти

**Рецепт: [чотири режими project instructions](https://raw.githubusercontent.com/anthropics/claude-code/main/mods/agents-md/README.md) у Claude Code — не тільки «AGENTS.md замість CLAUDE.md»**

У мода `agents-md` рівно одна опція, `instructionFiles`, і в неї чотири значення:
• `claude-md` — тільки CLAUDE.md, як було до 2.1.277
• `claude-md-or-agents-md` (дефолт) — AGENTS.md підхоплюється, якщо в проєкті немає свого CLAUDE.md
• `claude-md-and-agents-md` — вантажаться обидва, вгору і вниз по дереву; файл, який CLAUDE.md уже `@`-імпортує або на який лінкується, другий раз не береться
• `managed-only` — інструкції проєкту і твої власні викидаються з контексту, лишаються тільки керовані організацією та памʼять движка

У UI це рядок «Project instructions» у `/config`. Руками — так:

```json
{
  "pluginConfigs": {
    "agents-md@builtin": {
      "options": { "instructionFiles": "claude-md-and-agents-md" }
    }
  }
}
```

`claude-md-and-agents-md` рятує там, де в репозиторії вже лежить AGENTS.md від іншого агента і не хочеться тримати ті самі правила у двох файлах. `managed-only` — швидкий спосіб перевірити гіпотезу «а це не роздутий CLAUDE.md псує відповіді?».

Провенанс: README мода в офіційному репозиторії anthropics/claude-code, JSON дослівно звідти; сам не ганяв. Фіча в early access — API модів може мінятись між релізами без попередження.
