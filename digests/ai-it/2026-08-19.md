## 🚀 Моделі

**DeepReinforce [виклали Ornith-1.5](https://ornith.ai/ornith_1_5.html) — відкриті ваги під MIT, і флагман іде ніздря в ніздрю з Opus 4.8**

Три розміри, усі сьогодні на HF: 397B MoE, 35B-A3B (~3B активних) і 9B dense. База — Qwen 3.5, тож рантайми потрібні свіжі: Transformers ≥ 5.8.1, vLLM ≥ 0.19.1.

Цифри з анонсу:

| Бенчмарк | Ornith-1.5-397B | Claude Opus 4.8 | GLM-5.2 |
|---|---|---|---|
| Terminal-Bench 2.1 | 86.1 | 85.0 | 81 |
| DeepSWE | 56.0 | 59.0 | 46.2 |

Нове проти 1.0: моделі стали мультимодальними (у GGUF-репо лежить `mmproj`, в Ollama тег vision), контекст 262K нативно і до ~1M через YaRN.

35B на чотирьох квантах від Q4_K_M до Q8_0 — тобто реально запускається локально:

```bash
ollama run hf.co/ornith-ai/Ornith-1.5-35B-A3B-GGUF
```

Семпелінг з картки: `temperature=0.6`, `top_p=0.95`, `top_k=20`.

Найцікавіше тут не 397B, а 35B з трьома мільярдами активних параметрів — саме той клас, який влазить у робочий ноут і при цьому вміє в агентні таски.

## 🛠️ Інструменти

**Modular [відкрили Mojo](https://www.modular.com/blog/mojo-open-source) — компілятор і весь тулчейн під Apache 2 з LLVM-винятками**

Обіцяли з травня 2023, зробили зараз. Усе живе в монорепо [modular/modular](https://github.com/modular/modular), збірка через Bazel:

```bash
git clone https://github.com/modular/modular.git
cd modular
./bazelw run --config=build-mojo KGEN:mojo -- run hello.mojo
```

Якщо не хочеться компілювати компілятор — є `--config=prebuilt-mojo`, який тягне готові бінарники.

Simon Willison [нагадує](https://simonwillison.net/2026/Aug/18/mojo-is-now-open-source/) важливе: Mojo давно вже не «надмножина Python». Ще у серпні 2025 команда сказала, що може нею й не стати, — це окрема мова з Python-натхненним синтаксисом, заточена під GPU-програмування.

Тобто взяти свій .py і перейменувати в .mojo не вийде. Але як мова, у якій відкритий увесь стек, вона нарешті стала чимось, у що можна вкластися без ставки на одного вендора.

**[fx](https://fx.sh) — кодинг-агент на Zig, шість мегабайт бінарника і холодний старт за 10 мікросекунд**

Apache-2.0, версія 0.0.3 і чесна помітка «experimental». Автор позиціонує це не як ще один CLI, а як харнес, який можна вбудувати в більшу систему: компілюється у WebAssembly, тримає одноцифрові мегабайти памʼяті, модель-агностичний.

```bash
curl -fsSL https://fx.sh/setup.sh | bash
```

У [треді на HN](https://news.ycombinator.com/item?id=49353339) хвалять аскетичний вивід у дусі Unix shell і preserve-scroll. Критика теж конкретна:
• 26 вбудованих тулів погано вʼяжуться з гаслом про мінімалізм
• доки натякають на Vercel AI Gateway як основний шлях інференсу

Автор відповів, що підтримка Codex і Grok на підході.

Дивитись варто не як на заміну Claude Code, а як на заготовку: якщо тобі колись треба буде запхати агента всередину свого продукту, 6 МБ і 10µs — аргумент.

**Claude Code [2.1.235](https://code.claude.com/docs/en/changelog) — перевірка орфографії в промпті і полагоджені діалоги дозволів**

Реліз майже цілком з фіксів, але кілька зачіпають щоденне:
• опційний сеттинг `spellcheck` підкреслює одруковані слова прямо в полі вводу, спираючись на встановлений `aspell`, `hunspell` чи `ispell`
• Shift+Tab у полі коментаря до permission-промпту більше не аппрувить правку і не роздає дозвіл на всю сесію
• тексти в діалогах дозволів тепер збігаються з тим, що насправді дасть грант, а «don't ask again» ховається, коли вміст не показати повністю
• вкладені markdown-списки перестали розʼїжджатись з третього рівня

Ще підрихтували памʼять і CPU, поки у фоні крутяться хмарні сесії типу `/ultrareview` чи `/autofix-pr`: їхні стріми більше не перечитуються на кожен апдейт.

Фікс Shift+Tab — той рідкісний випадок, коли баг тихо роздавав права ширше, ніж ти думав. Оновитись варто хоча б заради нього.

## 💡 Рецепти

**[Graft](https://github.com/NanoNets/Graft) будує граф твоєї кодбази і підсовує його агенту через хуки Claude Code**

Ідея: замість того щоб агент кожну сесію заново гріб `grep`-ом по репо, один раз побудувати структурний граф і віддавати його наперед.

```bash
npm install -g @nanonets/graft
graft init
```

Або без глобального встановлення:

```bash
npx @nanonets/graft init
```

`graft init` сам прописує хуки в `.claude/`: граф пересинхронізовується після правок, зʼявляється попередження про blast radius при зміні файлу і статуслайн зі свіжістю графа. Для Cursor кладе `.cursor/rules/graft.mdc`, для решти — `AGENTS.md`.

Граф двошаровий: структура через tree-sitter (без LLM і без ключа), а поверх — опційні концепт-ноди з LLM-самарі (флаг `--deep`, потребує ключа й коштує грошей). Сам граф лягає в локальну теку `graft/` і додається в `.gitignore`.

Сам не тестив. Ліцензія MIT, команди — з README проєкту. Цифру «−42% токенів» дають самі автори: їхній бенчмарк на 162 прогонах по двох репозиторіях із Sonnet 5, тож ставитись варто як до вендорського заміру, а не незалежного. Заявлена підтримка 21 мови з різною якістю розбору.

Спробувати дешево: tree-sitter-шар не вимагає ключа взагалі, тож перший `graft init` нічого не коштує.

## 📌 Рухи й безпека

**Anthropic [нагадали, що промо на тижневі ліміти Claude Code закінчується](https://support.claude.com/en/articles/15910845-claude-code-may-august-2026-weekly-limits-promotion) 31 серпня**

З 13 травня тижневий ліміт у Claude Code був на 50% вищим за штатний. Після 31 серпня він повертається до звичайного рівня — без змін у тарифі й білінгу, просто стеля стає нижчою.

Деталі, які легко проґавити:
• пʼятигодинні ліміти промо не зачіпало взагалі, тільки тижневі
• діяло на Pro, Max, Team і legacy seat-based Enterprise; Free і consumption-based Enterprise — ні
• стосується Claude Code на всіх платформах (CLI, IDE, десктоп, веб), інші продукти Claude не зачеплені

Якщо останні місяці ти впирався в тижневу стелю під кінець тижня — з вересня впиратимешся приблизно на третину раніше. Непоганий момент перерахувати, чи вистачає плану, до того як воно застане посеред задачі.
