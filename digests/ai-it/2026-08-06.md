## 🛠️ Інструменти

**Meta [зарелізили Muse Code](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2) — свій термінальний агент, beta для macOS і Linux**

Ставиться однією командою:

```bash
curl -fsSL https://dev.meta.ai/install.sh | bash
cd /path/to/your/project
muse
```

Заявлений сценарій — великі репозиторії: спланувати зміну, написати код, перевірити результат. Фонові агенти живуть протягом усієї сесії, кожен у власному ізольованому worktree, робочу копію не чіпають. Події пишуться локально, тож після краху сесія піднімається з місця падіння.

У кейсі з анонсу агент ітеративно оптимізував GPU-кернел понад 1000 викликів тулів.

Windows нема, GUI нема — тільки CLI.

Команда встановлення підтверджена двома незалежними оглядами (9to5Mac і незалежний гайд), офіційна сторінка `dev.meta.ai` віддається тільки після логіну. Перед запуском curl-пайпа варто прочитати сам скрипт і умови авторизації, і стартувати в репозиторії, який не шкода.

#tools

**Claude Code [оновився до 2.1.223](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) — знову фікс обходу дозволів у Bash, і цього разу до нього додалась втеча з пісочниці**

Безпекова частина релізу:
• спеціально складені Bash-команди могли сховатись від перевірки дозволів
• команди з паддінгом підмінювали те, що ти бачиш у промпті підтвердження
• workflow-скрипти через динамічний `import()` виконували код поза пісочницею
• `bypassPermissions` в описі агента ігнорував org-політику, яка це забороняє

Це третій день поспіль з фіксом обходу перевірки дозволів — 221 закривав діру в zsh, 222 в worktree-ізоляції.

З решти корисного:
• `/review` тепер аліас до `/code-review`, а `/code-review` перевикористовує останній рівень effort
• `CLAUDE_CODE_DISABLE_1M_CONTEXT` більше не вимикає моделі, а тримає всі 1M-моделі на 200K через автокомпакцію
• в managed settings зайшли wildcard-и виду `"owner/*"` для дозволу чи блоку marketplace-репозиторіїв
• `/teleport` підказує, як продовжити хмарну сесію локально

Оновлюватись сьогодні, не «колись потім».

## 💡 Рецепти

**Simon Willison [за один промпт зібрав 3D-гру для браузера](https://simonwillison.net/2026/Aug/5/raccoon-heist/) на Claude Fable 5 — і промпт тут цікавіший за гру**

Запускав у Claude Code for web, далі не втручався. Текст промпту:

```text
Build this 3D game, for the browser.

This repo is configured to serve static files so make sure there is
an index.html that loads everything else.

Make sure it is mobile-friendly (touch controls, works well on small screens).

You have an OpenAI API key and access to their image generation model APIs,
use that for textures to use with your 3D models. Docs here:
https://developers.openai.com/api/docs/guides/image-generation - use gpt-image-2

Work independently - do not ask me to make any further design decisions.
Make sure the game is fun, a little surprising, has good raccoon heist vibes,
and is visually pleasing.

Commit and push as often as possible so I can preview your work - start with
an index.html that presents a title screen, then build from there.

Append to a notes.md file as you work, including your changes to that
as part of every commit.
```

Чотири прийоми, які варто тягнути в свої задачі:
• явна заборона повертатись із питаннями — інакше довга автономна сесія стає діалогом
• «коміть і пуш якомога частіше», щоб дивитись прогрес прев'ю, а не читати транскрипт
• `notes.md` як журнал, який оновлюється в кожному коміті
• перший крок задано вручну (title screen), решта — на модель

На виході Three.js без CDN, текстури з gpt-image-2, звук процедурний через WebAudio. Сам автор чесно каже, що геймплей так собі.

▶ [Пограти в результат](https://simonw.github.io/raccoon-heist/) • [код](https://github.com/simonw/raccoon-heist/)

Це його реальний запуск із відкритим транскриптом, не переказ; сам я цю схему не тестив. Але каркас промпту переноситься на будь-яку задачу «зроби прототип і не турбуй мене».

## 📌 Рухи й безпека

**PromptArmor [показали zero-click витік даних з Atlassian Rovo](https://www.promptarmor.com/resources/atlassian-rovo-exfiltrates-data) — і Atlassian мовчить із травня**

Як працює:
• в завантажений файл кладуть приховану інструкцію
• ти питаєш Rovo щось звичайне — розкидати тікети по Jira
• інструкція змушує агента дописати чутливі дані в кінець URL атакера
• тул для роботи з URL цей лінк відкриває, дані лягають у логи

Ключова деталь: тул не перевіряє динамічно зібрані URL, тому організаційне вимкнення веб-пошуку атаку не спиняє. Кліків від жертви не потрібно взагалі.

Репорт відправили 23 травня, Atlassian підтвердили отримання 25-го і далі не відповідали. На момент публікації 5 серпня діра відкрита.

Якщо Rovo стоїть у вашому Jira чи Confluence — до нього краще не пускати файли з невідомих джерел, доки не буде фіксу. Заразом привід перевірити, що вміє відкривати URL кожен ваш агент.
