## 🚀 Моделі

**Google [зарелізили EmbeddingGemma 2](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) — 740M мультимодальних ембедінгів під Apache 2.0, які крутяться на телефоні**

• текст, код, картинки, відео й аудіо в одному 768-вимірному просторі
• контекст 8K токенів — це ~5.5 хвилини аудіо, 29 картинок або 58 кадрів відео
• модульна: тільки текст — 270M, текст+картинки — 440M, текст+аудіо — 570M, усе разом — 740M
• MTEB Code підріс з 68.76 до 78.68
• у квантизації на Pixel 11 Pro — 191 МБ RAM на текстовій частині, 567 МБ на повній

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("google/embeddinggemma-2")
```

Matryoshka дає обрізати вектор до 512, 256 чи 128 вимірів: на мільйоні векторів у bfloat16 це 1.5 ГБ проти 250 МБ. Ваги на [HF](https://huggingface.co/google/embeddinggemma-2) і Kaggle, є збірки під Ollama і LM Studio.

Один простір на всі модальності означає, що текстовим запитом можна шукати по картинках і аудіо без окремої моделі під кожну. Плюс Apache 2.0 — тобто без лок-іну на провайдера, коли одного дня доведеться переембедити все сховище.

**OpenAI [відкрили Decisions API у публічну бету](https://developers.openai.com/api/docs/guides/decisions) — окремий ендпоінт для швидких рішень, де платиш тільки за вхід**

Працює лише на `gpt-6-luna`. Кидаєш у `POST /v1/decisions` спільний інпут (текст або повідомлення з картинками) і список питань трьох типів:
• `predicate` — умова, вертає ймовірність 0..1
• `choice` — вибір з фіксованих опцій, з масивом `probabilities` і полем `confidence`
• `score` — оцінка по впорядкованих рівнях, може впасти і між ними

Ціна — \$0.10 за млн вхідних токенів, і дослівно з доків: «You pay only for input tokens: there are no cache-read, cache-write, or output-token charges». Обіцяють «about 10x faster than the Responses API», GA — «in the coming weeks».

Це рівно ті задачі, на які зазвичай палиш звичайну модель: роутинг, класифікація, guardrails, вибір наступного кроку агента. Окремий ендпоінт без оплати виходу робить такі дрібні виклики на порядок дешевшими.

Дві штуки:
• [`d1-3B`](https://huggingface.co/LiquidAI/d1-3B) — декодер, текст і картинки, середній скор 82.9 по семи датасетах — вище, ніж у Decider 4B
• [`d1-omni-600M`](https://huggingface.co/LiquidAI/d1-omni-600M) — експериментальний двонапрямний енкодер, текст плюс картинки або аудіо, 78.4; обганяє Decider 2B, маючи втричі менше параметрів

Латенсі d1-3B на Jetson: 16 мс на AGX Thor, 26 мс на AGX Orin, 50 мс на Orin Nano.

```
pip install "transformers>=5.14" torch torchvision pillow
```

```python
AutoModel.from_pretrained("LiquidAI/d1-3B", trust_remote_code=True)
```

Ваги відкриті, є демо-спейс System One Arcade на HF — десять прикладів по камері, малюнку і тексту.

Третій анонс decision-моделей за два дні: схоже, «швидкі типізовані рішення» виділяються в окремий клас моделей. Якщо треба класифікувати потік локально і без мережі, 600M за 50 мс виглядає цікавіше, ніж ганяти на це фронтир-модель.

## 🛠️ Інструменти

**Claude Code [у 2.1.292](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) дає задавати рівень ефорту субагенту і ставити плагін одразу з маркетплейсу**

Що поклали:
• `effort` в Agent tool — субагент стартує на тому рівні, який попросив
• `claude plugin install --marketplace <source>` — додає маркетплейс, якщо його ще немає, і одразу ставить плагін
• промпт-кешування в `$.model.complete` для модів: `cache: true` на блоці кешує запит до нього
• `prompt.autocomplete` — хук, яким мод додає свої рядки в автокомпліт промпта
• `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS` — довша база бекофу на 529

Фіксів у релізі дуже багато, і серед них окрема помітка Security: PreToolUse-хуки й auto mode проскакували перміт-промпт на читанні файлів з UNC-шляхів.

Найпрактичніше тут `effort` на субагентах: пошук по репо тепер можна віддати дешевому рівню, а розбір архітектури — дорогому, не виходячи з однієї сесії.

**Cursor [показує локальні агенти в iOS-застосунку](https://cursor.com/changelog/remote-control-local-agents) — самі агенти лишаються на твоїй машині**

Як завести: ставиш Cursor iOS і логінишся, компʼютери з акаунта зʼявляються в застосунку самі. Тапаєш свій, підтверджуєш паринг у десктопному Cursor — і бачиш список локальних агентів. Можна подивитись, що агент робить, і написати йому.

Дослівно з ченджлогу: «Remote control doesn't move your agents anywhere. It keeps running on your computer, and the app connects to it». Тобто комп має лишатись включеним і онлайн.

Щоб ноут не засинав, є галочка «Keep this computer awake» в десктопних налаштуваннях Remote Control — але працює, тільки якщо він у розетці й з відкритою кришкою. Увімкнено за дефолтом усім, крім Enterprise: там адмін вмикає в Org settings → Security and identity → Remote control.

Цікаво порівняти з Cowork, який вчора поїхав у клауд: Cursor вибрав протилежне — нічого з машини не виносити, просто дати до неї пульт. Для тих, у кого код не має покидати ноут, це важливіше за хмарних агентів.

## 💡 Рецепти

**Рецепт: [strands-decider](https://github.com/strands-labs/strands-decider) підіймає локальний роутер на 2B, що відповідає за ~115 мс**

Apache 2.0, 494 зірки. Під капотом Qwen3.5-2B-Base з pointer head на ~1M параметрів і LoRA-адаптером rank-16.

```bash
pip install strands-decider
```

Спитати вибір з варіантів:

```bash
strands-decider ask StrandsAgents/strands-decider-2B-hobson-v21 \
  --state "Help! My payouts have been failing for 3 days! " \
  --choice "Which team should handle this?=billing,sales,retail"
```

Так само yes/no:

```bash
strands-decider ask StrandsAgents/strands-decider-2B-hobson-v21 \
  --state "Help! My payouts have been failing for 3 days! " \
  --noul "Does this convey urgency?"
```

А щоб смикати з коду — підняти сервером:

```bash
strands-decider serve StrandsAgents/strands-decider-2B-hobson-v21 --port 8000
```

```bash
curl -s localhost:8000/v1/systemone \
  -H 'content-type: application/json' \
  -d '{
    "state": "Help! My payouts have been failing for 3 days!",
    "questions": {
      "is_urgent": {"type": "noul", "instructions": "Does this convey urgency?"}
    }
  }'
```

Заміри авторів на v21: 76.2% на JevBench і медіанна латенсі 115 мс на RTX 3090, 153 мс на M3 MacBook. Сам не тестив — усі команди й числа взяті з README репозиторію.

Якщо в тебе є пайплайн, де модель лише сортує тікети чи вибирає тул, це той випадок, коли 2B локально дешевше і швидше за будь-який виклик в API. MLX-ускорення під Apple Silicon автори обіцяють наступним релізом.
