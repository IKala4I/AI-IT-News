**DeepSeek [тихо викотили V4 Pro 0813](https://openrouter.ai/deepseek/deepseek-v4-pro-0813) — GA флагмана з мільйоном контексту за \$0.435/\$0.87**

Ні поста, ні анонсу — модель просто з'явилась в API-доках і в OpenRouter. Контекст 1 048 576 токенів, максимальний вихід 384 000, кеш-хіт коштує \$0.003625 за мільйон.

Разом з нею [задокументували Responses API](https://api-docs.deepseek.com/guides/responses_api/): той самий формат, що в OpenAI, тож клієнт міняється двома рядками.

```python
from openai import OpenAI
client = OpenAI(api_key="<your DeepSeek API Key>", base_url="https://api.deepseek.com")
response = client.responses.create(
    model="deepseek-v4-flash",
    instructions="You are a helpful assistant.",
    input="Hi, how are you?",
)
```

Імена моделей — `deepseek-v4-flash` і `deepseek-v4-pro`. Є серверний веб-пошук через тули `web_search` / `web_search_2025_08_26` і стрімінг семантичними SSE.

Мільйон контексту за пів долара — це той діапазон цін, у якому не шкода згодовувати моделі цілий репозиторій замість того, щоб вигадувати розумний retrieval.

## 💡 Рецепти

**Локальний кодинг-агент у три команди — [llama.cpp плюс Pi](https://llama.app/)**

На llama.app зʼявився готовий сценарій, у якому агент сам знаходить твою локальну модель — без ключів, конфігів і base_url руками.

Спочатку єдиний бінар llama.cpp:

```bash
curl -LsSf https://llama.app/install.sh | sh
```

Під Windows той самий інсталер через PowerShell:

```powershell
irm https://llama.app/install.ps1 | iex
```

Далі піднімаєш сервер і чіпляєш плагін:

```bash
llama serve
pi install git:github.com/huggingface/pi-llama
pi
```

`pi-llama` [автоматично витягує моделі](https://github.com/huggingface/pi-llama) з запущеного llama.cpp-сервера і реєструє їх як провайдер `llama-cpp`. Перемикатись між ними — командою `/model` уже всередині Pi. Якщо сервер не на дефолтному порту, URL і ключ задаються env-змінними.

Бонусом бінар тепер уніфікований, у стилі `git`: `llama serve` замість `llama-server`, `llama cli` замість `llama-cli`. Старі окремі бінарі теж лишились робочими.

Усе — з офіційного сайту llama.app і README плагіна від Hugging Face; сам не ганяв.

Найкращий на сьогодні варіант для коду, який не можна віддавати назовні: нічого не летить у мережу, і налаштувати це справді швидше, ніж описати.
