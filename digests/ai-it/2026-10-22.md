## 🛠️ Інструменти

**Anthropic [запустила Claude Duet](https://claude.com/resources/articles/claude-duet): окремий застосунок, де Claude на Opus 5.5 сам стежить за твоїми сервісами і пише першим, коли щось потребує уваги**

**Коли знадобиться:** тонеш у пошті, Slack і календарі й хочеш зранку бриф, що горить, разом з готовими чернетками відповідей.

**Як виглядає:** пишеш задачу в один тред, а Duet працює на власному хмарному комп'ютері, тож ноутбук можна закрити. Перед листом чи оплатою чекає на твоє «ок».

**+** входить у Pro і Max, бере пам'ять, скіли й конектори з Claude
**−** лише США через вейтліст, фонові перевірки їдять ліміт підписки

Це помічник для рутини довкола роботи, для коду лишається Claude Code. На [HN](https://news.ycombinator.com/item?id=50186037) порівнюють з OpenAI Dots і сумніваються, чи давати агенту пошту й паролі.

## 📌 Важливо знати

**Anthropic [випустила нову версію Claude API `2026-10-21`](https://platform.claude.com/docs/en/release-notes/api), і свіжі мажорні SDK вмикають її самі: `@anthropic-ai/sdk` 1.0.0, Python SDK 2.0.0 та інші.**

Що зламається після оновлення:
• `temperature`, `top_p` і `top_k` дають помилку 400, навіть зі значенням за замовчуванням
• ключ іде в `Authorization: Bearer`, а не `X-Api-Key`, тож перевір свій проксі

Старі SDK працюють як раніше. Для переходу в Claude Code є `/claude-api api-version`, а решта змін у [гайді з міграції](https://platform.claude.com/docs/en/api/migration-2026-10-21).

## ✨ Цікавинка

**Розробник [навчив невелику модель вдавати термінал Linux](https://simedw.com/2026/10/21/world-model-terminal/): під капотом немає ні комп'ютера, ні файлів, модель просто вгадує, що має з'явитися на екрані після кожного натискання клавіші.** При цьому вона тримає світ цілісним: автор створив файл, змінив його у vim і прочитав зміни з іншого вікна, а ще пограв у цьому «терміналі» в Snake. Жодних правил, як працюють shell чи vim, ніхто не прописував, модель вивчила все із записів реальних сесій. Спробувати можна [прямо в браузері](https://simedw.com/projects/worldtui) на десктопному Chrome.
