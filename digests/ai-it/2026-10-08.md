• вхід \$0.10 / \$0.50
• вихід \$0.50 / \$2.50

**OpenAI [розкатали GPT-6 на всі тарифи ChatGPT](https://openai.com/index/gpt-6-for-everyone/) разом з Intelligent UI — відповідь тепер може бути інтерфейсом, а не текстом**

• 7 жовтня — Plus, Pro, Business і Enterprise у табі Chat, на GPT-6 Sol
• 8 жовтня — Free і Go, на GPT-6 Luna
• моделі під Work і Codex не змінились

Intelligent UI збирає відповідь з тексту, графіки й інтерактиву: калькулятор, спліт рахунку, клікабельна діаграма. Під капотом бібліотека стрімабельних компонентів і компілятор, що рендерить інтерфейс поки модель генерує, тому UI приїжджає частинами.

За замірами OpenAI, на пошукових питаннях GPT-6 Instant починає відповідати на 44% швидше за GPT-5.6 Instant.

Деталі — за [переказом анонсу](https://www.unite.ai/openai-brings-gpt-6-with-intelligent-ui-to-all-chatgpt-tiers/): сторінку openai.com віддають лише браузеру, скриптом її не дістати.

Для API нічого не змінилось, тож як інструмент це поки цікаве радше як сигнал: генерація готового UI замість markdown — наступне, що почнуть просити в продуктах.

## 🛠️ Інструменти

**Claude Code [у 2.1.293](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) ставить Haiku 5.5 дефолтним Haiku і лагодить CLAUDE.md, який не підхоплювався при читанні файлів через Bash**

Головне з ~55 рядків релізу:
• `claude-haiku-5-5` — тепер дефолтна Haiku-модель на Anthropic API
• path-scoped правила і вкладені CLAUDE.md не вантажились, коли Claude дивився файл через `cat`, `head`, `tail`, `sed -n` чи `grep` у Bash замість Read
• Claude перестав вважати власні дії перед компакшеном зробленими після нього і відкочувати готову роботу
• `agentType` у `subagentStatusLine` — скрипт тепер розрізняє типи субагентів
• `isDeferred` у `$.tool.register` для модів: `false` кладе схему тула в промпт одразу, а не за tool search
• полагодили втечу памʼяті, де HTTP MCP-конекшн тримав усі відправлені запити до закриття

2.1.294 — два рядки, обидва про хуки-інструкції: `prompt` і `agent` хуки на кшталт «Block commands that...» пропускали те, що мали блокувати.

Фікс CLAUDE.md тут найдорожчий: якщо ти в auto mode, де агент читає файли через Bash, твої path-scoped правила могли просто не діяти.

#tools

**GitHub Copilot CLI [показує локальні моделі з Ollama](https://github.blog/changelog/2026-10-07-discover-local-models-in-github-copilot-cli) прямо в `/model`**

З версії CLI 1.0.94-0 команда `/model` перелічує моделі запущеного інстансу Ollama поруч із клауд- і своїми налаштованими. Вибираєш, дивишся провайдера та ендпоінт, підтверджуєш «Add and use for this session» або «Add without switching».

Ollama і сама модель мусять бути встановлені заздалегідь — флоу нічого не ставить і не тягне. Модель має вміти tool calling і стрімінг.

Офлайн-режим окремий і тільки opt-in:

```
COPILOT_OFFLINE=true
```

Дисклеймер з ченджлогу важливий: вибір локальної моделі сам по собі не вмикає офлайн і не вимикає телеметрію GitHub, а віддалений провайдер і в офлайні може отримати промпт та контекст коду.

Якщо тримаєш Ollama для дрібних задач, це економить окремий BYOK-конфіг. Але «локально» тут про інференс, не про приватність.

## 💡 Рецепти

**Рецепт: віддати пошук по репо субагенту на Haiku 5.5 з низьким ефортом**

У 2.1.293 аліас `haiku` з'їхав на Haiku 5.5, а фронтматер субагентів приймає і `model`, і `effort`. Тобто дорогий пошук «де тут це лежить» можна зняти з головної моделі одним файлом.

Кладеш у `.claude/agents/repo-scout.md`:

```markdown
---
name: repo-scout
description: Finds where things live in the repo — files, symbols, call sites
tools: Read, Glob, Grep
model: haiku
effort: low
---

You locate code. Report file paths with line numbers and a one-line note
for each. Do not propose fixes.
```

Що варто знати з доків:
• `model` приймає `sonnet`, `opus`, `haiku`, `fable`, повний ID або `inherit`
• `effort` — `low`, `medium`, `high`, `xhigh`, `max`; перебиває ефорт сесії, але не змінну `CLAUDE_CODE_EFFORT_LEVEL`
• `.claude/agents/` — на проєкт, `~/.claude/agents/` — на всі; зміни підхоплюються за кілька секунд
• рестарт потрібен лише якщо створюєш перший файл у новій папці `agents`

Усі поля і значення — з [офіційних доків sub-agents](https://code.claude.com/docs/en/sub-agents); сам конфіг я склав з них, це не готовий приклад зі сторінки.

Сенс простий: Grep по монорепо не потребує фронтир-моделі, а на Haiku 5.5 до 100K токенів це \$0.10 за млн вхідних. Головну сесію при цьому не засмічує портянка з результатами пошуку — субагент віддає лише підсумок.

## 📌 Рухи й безпека

**Anthropic [дають підписникам Max і Team щомісячний кредит на API](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans) — \$100 на Max 5x і \$200 на Max 20x**

• Max 5x — \$100/міс, Max 20x — \$200/міс
• Team — \$20 за Standard-сіт і \$100 за Premium, у спільний баланс, але не більше \$500/міс
• Free, Pro і Enterprise не підпадають; підписка має бути активною сім днів до клейму

Кредити не переносяться — дослівно: «Unused credits expire at the end of each billing cycle». І витрачаються раніше за куплені.

Клеймити вручну: Settings → Billing на claude.ai, секція API credits → Link organization, прив'язати Console-організацію. Прив'язати можна лише одну, і перемкнути її самому вже не вийде — тільки через support.

Покривають Messages і Message Batches API, Console Playground, Managed Agents і Agent SDK. Не покривають інтерактивний Claude Code, Bedrock, Vertex і Foundry.

Фактично підписка на Max тепер приблизно дорівнює собі ж у кредитах на API — тобто пет-проєкти на Agent SDK можна гонити без окремого білінгу. Мінус один: не забути клікнути кнопку, бо несписане просто згорає.
