## 🚀 Моделі

**OpenBMB [зарелізили MiniCPM5-2B](https://huggingface.co/openbmb/MiniCPM5-2B) — 2.5B під Apache 2.0 з 131K контексту і офіційними GGUF**

З картки моделі: 2 516 756 480 параметрів (1.98B поза ембедингами), 42 шари, GQA 16/2 голови, нативний контекст 131 072 токени, BF16.

Цифри автори дають такі: середні 53.9 по 34 бенчмарках проти 51.1 у Qwen3.5-4B, 97.1 на τ²-Bench Telecom за tool use і 69.1 на LiveCodeBench v6. Artificial Analysis ставить 15 по Intelligence Index — найвище серед відкритих моделей до 4B.

```bash
pip install "vllm>=0.21"
vllm serve openbmb/MiniCPM5-2B --port 8000
```

Поруч від тих самих авторів лежать `openbmb/MiniCPM5-2B-GGUF` для llama.cpp, Ollama і LM Studio та `openbmb/MiniCPM5-2B-MLX` під Apple Silicon. Плюс base-модель, SFT-чекпоінт і проміжні.

Модель на 2.5B, якій не соромно дати tool calling, — цікава саме під локальні агенти на ноуті чи телефоні, куди 30B не влізе.

## 🛠️ Інструменти

**Terrastruct [відкрили TALA](https://d2lang.com/blog/tala-is-open-source/) — платний движок розкладки діаграм тепер MPL-2.0 і їде разом із D2**

TALA — ортогональний layout: замість «згори вниз по графу» він тягне до того, як діаграми малюють на вайтборді, і оптимізує симетрію, відступи, потік і кластеризацію вузлів.

Вмикається прапорцем або змінною, кількість спроб розкладки крутиться через `--tala-seeds`:

```bash
d2 --layout=tala arch.d2 arch.svg
export D2_LAYOUT=tala
```

У тому ж D2 v0.9.0: рендер SVG приблизно вдесятеро швидший на тестовому корпусі, самі SVG на ~24% менші, а вбудований рендерер навчився PNG, GIF, PDF і PPTX. Markdown-лейбли тепер нативний SVG замість `foreignObject`.

Мінуси автори пишуть чесно: у TALA є рандом, тож дрібна зміна вхідних даних дає іншу картинку, DAG-и він розкладає не оптимально, на великих діаграмах масштабується нелінійно.

Якщо тримаєш архітектурні діаграми в репо як код — рідкісний випадок, коли платна фіча просто стала безплатною.

## 💡 Рецепти

**Рецепт: [скіл, що змушує агента класти відповідь у перший рядок](https://github.com/ayghri/i-have-adhd)**

i-have-adhd — плагін із десятьма правилами формату: спершу команда, шлях або сніпет, далі нумеровані кроки по одній дії, ліміт 5 пунктів у списку, без преамбул і фінальних резюме.

Ставиться як маркетплейс-плагін:

```bash
claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd
```

Далі `/i-have-adhd`, коли прилетіла стіна тексту. В `INSTALL.md` є окремі команди під Codex, Cursor, OpenCode, Gemini, Qwen, Kimi і Antigravity.

Команди дослівно з `INSTALL.md`, сам не ставив. Головне заперечення в треді на HN (71 голос, 59 коментарів): те саме дають два рядки в `CLAUDE.md` або вбудований output style `Concise`, і що Claude тримає стислість кілька ходів, а далі забуває.

Ще деталь, яку варто знати перед установкою: у репо лежить `AGENTS.md` із секцією «AI Agora», що дозволяє агентам самим писати коментарі в issue #127. Тобто разом зі скілом ти тягнеш і інструкції для свого агента — прочитай їх, перш ніж ставити.
