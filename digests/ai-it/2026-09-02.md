## 🚀 Моделі

**Anthropic [зарелізили Claude Fable 5.1 і Mythos 5.1](https://www.anthropic.com/claude-fable-and-mythos-5-1) — та сама ціна за токени, але читання з кешу подешевшало вчетверо**

Обидві моделі — це один і той самий движок з різним рівнем safeguards. Fable 5.1 доступна всім, Mythos 5.1 — тільки верифікованим організаціям США через Cyber і Life Sciences Verification Program.

Цифри з анонсу:
• \$10 / \$50 за Mtok — без змін
• читання з кешу: \$1.00 → \$0.25 за Mtok
• −25% на типових задачах, до −45% на агентних
• Terminal-Bench-Science 0.1: 24.7% → 52.6%
• Terminal-Bench 4.0: 42.0% → 55.8% (Mythos — 60.9%)
• CursorBench 3.2.0: 70.5% → 73.4%

API-ID `claude-fable-5-1`, контекст 1M. Уже на Claude.ai, AWS, Google Cloud і Azure.

Найцікавіше тут не бенчмарки, а прайс на кеш: якщо ганяєш довгі агентні сесії з важким системним промптом, рахунок падає сам, без жодних змін у коді. А подвоєння на Terminal-Bench-Science — прозорий натяк, під що саме модель точили.

**Google [випустили Gemini 3.8 Flash і 3.8 Flash Cyber](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/) — рівно наступного дня після Fable 5.1**

Звичайний 3.8 Flash коштує \$0.75 / \$3.75 за Mtok, вступна ціна діє до 31 грудня 2026. Уже в AI Studio, Gemini API, Antigravity, Gemini Enterprise і в споживчих продуктах.

Заявлені результати:
• DeepSWE v1.1 — обганяє більшість більших фронтир-моделей
• CWE-Bench: 47.2% pass@1 на патчингу вразливостей
• HLE-Verified: 54.9%

Друга модель, 3.8 Flash Cyber, заточена суто під пошук і патчинг дірок: понад 70% успіху на внутрішньому бенчмарку по 20 мовах, а команда Chrome Security нарахувала в 2.6 раза більше коректних патчів, ніж у конкурентів. Роздають лише через нову Fairwind Program для «довірених захисників».

Flash за такі гроші з таким SWE-профілем — очевидний кандидат у дешеві субагенти під рутину. А те, що обидві лаби за два дні викотили окремі кібер-моделі під верифікацію, схоже вже на усталений патерн, а не збіг.

## 🛠️ Інструменти

**Claude Code [оновився до 2.1.257](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) — Fable 5.1 за замовчуванням і два нові запобіжники в auto-режимі**

Реліз великий, найпомітніше:
• Fable 5.1 став дефолтною Fable-моделлю
• `timeFormat` і `timeZone` — 12/24 години, UTC або власний strftime-патерн для годинника і транскрипту
• `permissions.blockReadsOutsideWorkingDirectories` — одноразовий запит перед першим читанням файлу поза робочими директоріями, з опцією заборонити такі читання взагалі
• правило Containment Escape: фетчі cloud metadata-креденшелів, обхід egress-обмежень і крос-тенантні звернення більше не автоапрувляться
• `s` у `/effort` — змінити effort лише на поточну сесію, як у `/model`

З фіксів вартих уваги: `/add-dir` більше не відмовляє для піддиректорій cwd, плагіни не читають файли поза власною текою через симлінки, а deny-правила на Bash нарешті ловлять `< file` і читалки на кшталт `tac` та `egrep`. Наступна 2.1.258 — гарячий фікс запуску на macOS 12.

Якщо пускаєш Claude Code в auto-режимі на чужому коді, два нових запобіжники варті апдейту самі по собі.

## 💡 Рецепти

**Рецепт: [примусити всі субагенти](https://code.claude.com/docs/en/sub-agents) Claude Code ганяти на одній дешевій моделі**

Раніше `CLAUDE_CODE_SUBAGENT_MODEL` перебивалася і фронтматером агента, і параметром при виклику, а вбудовані Explore і Plan її взагалі ігнорували. У 2.1.257 з'явився прапорець, який закриває всі лазівки:

```bash
export CLAUDE_CODE_SUBAGENT_MODEL=haiku
export CLAUDE_CODE_SUBAGENT_MODEL_FORCE=1
```

Змінна приймає аліаси (`sonnet`, `opus`, `haiku`, `fable`) або повні ID типу `claude-sonnet-5`. Прапорець діє на субагентів, teammates і workflow-агентів — включно з Explore і Plan.

Два винятки, які лишаються на моделі головної розмови: fork поточної розмови і скіл, що ганяється в субагенті з `model: inherit`.

Офіційна фіча, синтаксис дослівно з документації; потрібен Claude Code v2.1.257+.

Найпростіший спосіб поставити стелю на витрати: головна розмова на Fable, вся рутина пошуку й читання — на Haiku, і жодне визначення агента цього не обійде.

## 📌 Рухи й безпека

**Mistral [за замовчуванням тренується на введених даних](https://help.mistral.ai/en/articles/455207-can-i-opt-out-of-my-input-or-output-data-being-used-for-training) — крім Enterprise-тарифу**

Зі сторінки підтримки, оновленої вчора:
• Vibe (звичайний) — ти НЕ виключений за замовчуванням
• Vibe Enterprise — виключений автоматично
• Mistral Studio / API — відмовитись можна, але автоматично тебе не виключають

Головна пастка — тумблери для Vibe і для API окремі. Вимкнув в одному, у другому все ще тренуються.

Де шукати: у вебі Admin panel → Vibe → Privacy → «Allow your interactions to be used to train our models»; у мобільному Settings → Data &amp; Account Controls → «Enable data sharing»; для Studio/API — Admin panel → Privacy → «Anonymous improvement data».

Вчора сторінка зібрала 215 балів на HN — тобто новина для більшості. Якщо ти хоч раз кидав у Mistral шматок клієнтського коду, це ті пʼять хвилин, які варто витратити просто зараз.
