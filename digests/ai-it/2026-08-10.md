## 🚀 Моделі

**Meta [виклали Muse Glimmer 30B](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model) під Apache 2.0 — агентну модель, розраховану на твоє власне залізо**

Це не чергова відкрита база, а модель під локальних кодинг-агентів. Ключове — вона реально влазить у споживчу відеокарту чи Mac.

Що заявляють:
• 30B параметрів, 128K+ контексту, 100+ мов
• 4-бітна квантизація — менше 20GB памʼяті, тобто 24-32GB VRAM
• мультимодальний вхід через окремий perception encoder на 1.8B
• SWE-Bench Verified 76%, SWE-Bench Pro 51.2%, MCP Atlas 75.5%
• спекулятивний декод через DFlash: 3.1× на RTX 5090, 1.5-1.8× на Apple Silicon

Ваги — `meta-models/Muse-Glimmer-30B`. Підхоплюють Ollama, LM Studio, llama.cpp, MLX, vLLM і SGLang.

![Muse Glimmer](https://huggingface.co/blog/assets/muse-glimmer/thumbnail.png)

Цифри — від самої Meta, незалежних замірів поки нема. Але 76% на SWE-Bench Verified у моделі, яка працює без інтернету, — це вже рівень, на якому локальний агент перестає бути іграшкою.

## 🛠️ Інструменти

**[Docker Sandboxes](https://www.docker.com/products/docker-sandboxes/) — одноразова microVM під кожного агента, щоб YOLO-режим перестав бути рулеткою**

Сьогодні продукт зібрав майже 500 балів на HN, хоча стартував ще навесні. Ідея проста: агент живе в одноразовій microVM з власною ФС, власним Docker-демоном і окремим мережевим стеком. Хост не чіпається взагалі.

```bash
brew trust docker/tap && brew install docker/tap/sbx
sbx login
cd ~/my-project && sbx run claude
```

З коробки — Claude Code, Codex, Gemini CLI, Copilot CLI, OpenCode, Kiro і кастомні агенти. Ядро безкоштовне; org-політики на мережу, ФС і MCP — в окремому Docker AI Governance.

У [v0.38.0 від 6 серпня](https://github.com/docker/sbx-releases/releases/tag/v0.38.0) додали `sbx mcp` — реєстр MCP-серверів з політиками Cedar, і експериментальний запуск Claude Code на локальній моделі.

![Docker Sandboxes](https://www.docker.com/app/uploads/2026/03/docker-sandboxes-agent-workspace-2320x1205.png)

Найпряміший спосіб пустити агента без нагляду і не молитись при цьому за свій `~/.ssh`.

**[Ante](https://github.com/AntigmaLabs/ante) — кодинг-агент в одному 15MB-бінарі, який уміє працювати без інтернету**

Сьогодні виїхав у Show HN. Rust, архітектура клієнт-демон, нуль рантайм-залежностей: ні Node, ні Python.

```bash
curl -fsSL https://ante.run/install.sh | bash
```

Головне тут — вбудований llama.cpp: GGUF крутиться прямо в бінарі, без API-ключів і без мережі.

```bash
ante --offline-model ~/.ante/models/Qwen3.5-9B-Q4_K_M.gguf \
  -p "add error handling to src/main.rs"
```

Онлайн теж працює: 12+ провайдерів через env-змінні чи OAuth, кастомні — в `~/.ante/catalog.json`. Заявляють 82.7% на Terminal-Bench 2.1 з відкритим DeepSeek V4 Flash і ~7× менше пікової памʼяті за Claude Code.

Код під Apache 2.0, бінар безкоштовний на час alpha preview, 774 зірки.

Заміри від авторів, тож віри на слово. Але формат «один бінар + офлайн-інференс» цікавий для ноутбука в дорозі й для репо, які не можна віддавати назовні.

## 💡 Рецепти

**Посади Claude Code на локальний Muse Glimmer — [`ollama launch`](https://ollama.com/blog/muse-glimmer)**

Ollama викотили модель у той самий день і одразу дали команду, яка підміняє бекенд Claude Code на локальну модель:

```bash
ollama run muse-glimmer:30b-mlx
ollama launch claude --model muse-glimmer:30b-mlx
```

`ollama launch` — не тільки про Claude: [в доках](https://docs.ollama.com/cli) є ще OpenCode, Codex, VS Code і Droid. Інтеграцію можна вибрати інтерактивно або тільки налаштувати, не запускаючи:

```bash
ollama launch
ollama launch droid --config
```

MLX-збірка йде з DFlash, тож на Apple Silicon генерація в 1.5-1.8 раза швидша. Reasoning має чотири рівні — low, medium, high, xhigh.

Якщо потрібна ще й ізоляція, Docker Sandboxes уміє те саме, поки експериментально:

```bash
sbx run --model ollama/muse-glimmer:30b-mlx claude
```

Усі команди — з офіційного блогу Ollama, доків Ollama і релізноутів sbx v0.38.0; сам не ганяв.

Найдешевший спосіб перевірити, чи витягне 30B твої реальні задачі: той самий харнес, ті самі скіли й хуки, просто інший бекенд і нуль токенів у рахунку.

## 📌 Рухи й безпека

**GitHub [вимкнули GitHub Models](https://github.blog/changelog/2026-07-30-github-models-is-now-retired/) — плейграунд, каталог, inference API і BYOK більше не працюють ні в кого**

Ретирували 30 липня, але [Simon Willison написав про це аж учора](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/) — схоже, багато хто досі не помітив. Вимкнули для всіх, включно з тими, у кого був активний ужиток.

Найболючіше — це був спосіб ходити в LLM з GitHub Actions по вже наявних GitHub-кредах, без окремого ключа. Тепер такі воркфлоу просто падають. GitHub пропонує Microsoft Foundry або Copilot; Simon у себе переїхав на OpenAI API з лімітом витрат.

Причин не пояснили. Версія Simon-а — безкоштовні токени не пережили того, скільки їх стали їсти кодинг-агенти.

Якщо десь у тебе лежить забутий Actions-воркфлоу з підсумовуванням issues чи README — перевір, він уже тиждень мовчки червоний.
