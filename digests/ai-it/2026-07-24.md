## 🚀 Моделі

**Anthropic випустили [Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)** — новий флагман з мільйонним контекстом і thinking увімкненим за замовчуванням

`claude-opus-5` вже доступний у Claude API, Claude.ai, Claude Code і Cowork; тепер дефолтна модель на Max-плані і найсильніша опція на Pro. Контекст — 1M токенів (і дефолтний, і максимальний), вихід — до 128k токенів. Ціна не змінилась відносно Opus 4.8: $5 / $25 за мільйон токенів вхід/вихід. Є Fast Mode — приблизно вдвічі швидший за подвійну ціну.

За заявою Anthropic, модель вдвічі покращила результат Opus 4.8 на Frontier-Bench v0.1, втричі випереджає конкурентів на ARC-AGI 3, і на OSWorld 2.0 обходить "Fable 5" за третину вартості.

Якщо тримаєте Claude Code чи Cowork на Max-плані — модель під капотом вже змінилась сама собою, без жодних дій з вашого боку.

**Black Forest Labs представили [FLUX 3](https://bfl.ai/blog/flux-3)** — одну модель для фото, відео й аудіо в єдиній архітектурі

Генерує зображення, відео (до 20 секунд) і аудіо в одному flow-based бекбоні. За заявленими сліпими порівняннями, відео-версія переважає Runway Gen-4.5 у 77% випадків, Luma Ray 3.2 — у 93%, Grok Imagine Video — у 69%. Окремо відзначають якість міміки облич і синхронізацію звуку з подіями на екрані.

Доступ поки через ранній доступ — відео вже відкрите, фото розкочують найближчими тижнями. Публічного API чи ваг ще немає, тільки форма запиту.

Сьогодні топ HN (500+ балів) — варто тримати в полі зору, навіть якщо руки дійдуть не одразу.

**[POCKET](https://huggingface.co/blog/FINAL-Bench/pocket)** — 35-мільярдна MoE-модель, яку можна ганяти на iPhone або ПК без GPU

Квантизований Darwin-36B-Opus (sparse MoE, ~3B активних параметрів на токен) у кількох варіантах: Q4_K_M (21GB), рекомендований Q2_K (13GB) і найлегший IQ1_M (8.2GB), плюс окремі мобільні білди на 5-6GB. За заявою авторів, швидше за конкурентний 1-бітний Bonsai-27B: 27 tok/s на CPU (Xeon, 16 потоків) проти 10.1, і 197 tok/s на H100 проти 89.

```bash
llama-cli -m POCKET-35B-Q2_K.gguf -p "prompt" -ngl 0 -t 8
```

Apache 2.0, працює через llama.cpp, LM Studio, Ollama чи MLX на Mac.

Якщо хочеться погратись з великою MoE-моделлю локально без хмарного API й без GPU — це один із небагатьох реальних варіантів спробувати просто зараз.

## 🛠️ Інструменти

**OpenAI [привезли голосове керування Codex на десктоп](https://techcrunch.com/2026/07/24/openais-new-voice-mode-makes-it-to-the-chatgpt-desktop-app/), а Anthropic того ж тижня прокачали Claude Voice Mode**

GPT-Live (full-duplex голосова модель) тепер працює в десктопному ChatGPT для Mac і Windows — можна голосом ставити задачі Codex-агентам, паралельно керувати кількома і перебивати модель на льоту. На macOS додався "Appshots" — модель бачить активне вікно й контекст екрана. Доступно на Plus, Pro, Business, Edu, Enterprise.

Claude Voice Mode тим часом [перестав бути прив'язаним до Haiku](https://techcrunch.com/2026/07/23/anthropic-updates-claude-voice-mode-with-more-capable-models/) — тепер можна голосом говорити з Opus чи Sonnet, модель підхоплює ту, якою ви востаннє юзали в тексті. Додались голосові дії в Gmail, Google Calendar, Slack, Canva й Notion. На безкоштовному плані — лише Haiku й один коннектор.

Обидва релізи в один тиждень — схоже, "керувати агентом голосом, не відриваючи рук від клавіатури" стає окремим напрямком гонки, а не нішевою фічею.

**GitHub Copilot [отримав хмарного агента для Linear у GA](https://github.blog/changelog/2026-07-23-copilot-cloud-agent-for-linear-is-now-generally-available)**, плюс апдейт MCP-сервера й контроль над агентськими правками в Issues

Признач Linear-ішью Copilot — і агент сам аналізує задачу, працює в ефемерному GitHub Actions середовищі, відкриває драфт PR і стрімить прогрес прямо в таймлайн Linear. Можна обирати модель, кастомного агента, base/working branch і керувати через коментарі під час виконання. Потрібен Copilot Pro/Pro+/Business/Enterprise, права organization owner в GitHub і admin у Linear-воркспейсі; ставиться додатком "GitHub Copilot for Linear" з GitHub Marketplace.

Того ж дня GitHub MCP Server додав підтримку майбутньої stateless-специфікації MCP (стартує 28 липня, без сесій і `initialize`-хендшейку), а Issues отримали Approvals і Confidence Ratings для агентських правок — шукати через `has:suggestions`.

Якщо вже ведете задачі в Linear поруч із GitHub — це закриває ще один розрив між тікетом і готовим PR без ручного передавання контексту.

**[OpenWorker](https://github.com/andrewyng/openworker)** — опенсорсний "AI-колега" на десктоп від Andrew Ng, відкрита бета

На відміну від чат-бота, віддає готовий результат: розбиває задачу на кроки, працює з файлами й підключеними тулами (GitHub, Slack, Jira, Notion, Linear, Gmail, термінал і будь-що через MCP), і питає підтвердження перед діями з наслідками — надсиланням повідомлень, зміною календаря, запуском команд.

```bash
git clone https://github.com/andrewyng/openworker
cd openworker
bash packaging/setup_dev_env.sh
.venv/bin/openworker-server --cwd ~/some/project --port 8765
```

MIT-ліцензія, працює з OpenAI, Anthropic, Gemini, Grok, Mistral і локальними моделями через Ollama.

Якщо OpenWorker хоч трохи повторить успіх курсів Andrew Ng у популяризації AI — варто придивитись раніше, ніж стане мейнстрімом.
