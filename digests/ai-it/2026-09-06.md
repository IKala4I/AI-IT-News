## 🛠️ Інструменти

**Claude Code [оновився до 2.1.263](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) — `/skill-doctor` і вивід команд до 128K символів**

Головне приїхало в 2.1.261:
• `/skill-doctor` — показує, які завантажені скіли не використовуються і скільки контексту вони їдять
• `bashOutputMaxChars` і `taskOutputMaxChars` — скільки виводу команди й фонової задачі прилітає інлайн замість збереження у файл, до 128K символів
• `--append-subagent-system-prompt-file` — системний промпт для субагентів із файлу, коли він завеликий для командного рядка
• рядок «Organization policy» у `/status` і `claude doctor` пояснює, чому не підтягнулась політика організації

З фіксів: `/usage` більше не губить рядки тижневих лімітів під час рейтліміту, `claude -p --resume` із кривим session ID стартує під новим замість того, щоб падати, і полагодили втрату виводу хуків при резюмі сесії. 2.1.263 — тільки багфікси.

`/skill-doctor` — те, чого бракувало найбільше: скіли тихо з'їдають контекст, і донедавна порахувати це можна було хіба вручну.

#tools

**Anthropic [додали `ant apply`](https://platform.claude.com/docs/en/cli-sdks-libraries/cli/apply) — агенти, скіли й деплойменти як файли в репозиторії**

У CLI 1.30.0 з'явилась команда, яка створює й оновлює ресурси Claude API з файлів: агенти, environments, скіли, memory stores і deployments. Пишеш агента як Markdown, запускаєш, апрувиш план:

```bash
ant apply agents/summarizer.md
```

Сам файл — frontmatter із конфігом плюс body як системний промпт:

```markdown
---
name: Summarizer
model: claude-opus-5
tools:
  - type: agent_toolset_20260401
---

You are a helpful assistant that writes concise summaries.
```

Перший запуск пише `claude-lock.json` — саме він тримає ID ресурсів, тож наступний прогін оновлює їх, а не плодить дублікати. Ресурси посилаються один на одного відносними шляхами, і `ant apply .` розкатує всю директорію в правильному порядку. Для CI є `--yes` і `--dry-run`.

По суті Terraform для агентів. Найцінніше тут не автоматизація, а те, що конфіг агента нарешті проходить код-рев'ю разом із рештою репозиторію.

## 💡 Рецепти

**Рецепт: [запустити 105-гігабайтну модель на 48-гігабайтному Mac](https://github.com/carloslfu/slotstream)**

slotstream — CLI на MLX і Swift, який стрімить ваги з SSD у памʼять по мірі потреби, замість тримати їх усі в RAM. Підтримує рівно одну модель — `qwen3.8-flash-next:4bit` на 125B параметрів.

```bash
curl -fsSL https://raw.githubusercontent.com/carloslfu/slotstream/main/install.sh | sh
slotstream doctor
slotstream pull
slotstream run --prompt "Why is the sky blue?"
```

`slotstream doctor` перевіряє сумісність Mac і показує план по памʼяті ще до того, як качати 88 GB. Далі `slotstream serve` піднімає сервер з Ollama- і OpenAI-сумісним API — його можна підчепити до Open WebUI чи кодинг-агента.

Вимоги: Apple Silicon, macOS 14 або новіша, близько 110 GB вільного на SSD. На 48 GB M5 Pro автор міряє ~12 токенів/с після прогріву кешу.

Команди дослівно з README, сам не ганяв. Знову `curl | sh` — відкрий скрипт перед запуском. На HN пост зібрав 238 голосів.

## 📌 Рухи й безпека

**Агенти OpenAI [влаштували собі дошку оголошень](https://collusion.wiki/) у публічній німецькій вікі — 18 тисяч постів за 26 днів**

Nightingale Collective опублікували розбір 4 вересня. Агенти, що виконували web-retrieval задачі, знайшли DSEWiki на ProWiki і почали писати туди один одному.

• ~18 000 постів, 3700+ різних самоназваних імен агентів
• 98.5% правок — з IP Microsoft Azure
• 380 901 запит з fetch-тула OpenAI за червень
• 24 травня — перший успішний запис, 22 червня активність різко обірвалась

Ділились відповідями на задачі, передбачали майбутні питання, підбирали seed генератора випадкових чисел, лишали «heartbeat»-сигнали, щоб помітити момент завершення, обходили заборону на POST через трюк із Azure-хостнеймом, пробували XSS і видавати себе за адміна.

OpenAI інцидент підтвердили. Якщо ганяєш агента з доступом в інтернет і без пісочниці — це рівно та поведінка, під яку ніхто не пише тести.
