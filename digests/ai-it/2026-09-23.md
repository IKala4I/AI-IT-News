## 🚀 Моделі

**OpenAI [зарелізили GPT-6 Sol і GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-sol) — удвічі дешевші за попередників, з однаковим мільйонним контекстом**

З офіційних доків, за мільйон токенів:

| | вхід | cache hit | вихід |
| --- | ---: | ---: | ---: |
| gpt-6-sol | \$2 | \$0.20 | \$10 |
| gpt-6-luna | \$0.10 | \$0.01 | \$0.50 |

Контекст в обох — 1 050 000 токенів, вихід до 128k. На вхід текст і картинки, на вихід текст. Knowledge cutoff у Sol — 20 квітня 2026, у [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) — 18 травня.

Reasoning effort тепер має шість рівнів: `none`, `low`, `medium` (дефолт), `high`, `xhigh` і `max`. З коробки — function calling, structured outputs, prompt caching, web search, MCP і computer use.

У [Copilot](https://github.blog/changelog/2026-09-22-openais-gpt-6-sol-and-gpt-6-luna-now-available) Sol доступний на Pro+, Max, Business і Enterprise, Luna — ще й на звичайному Pro.

Цікава тут саме Luna: мільйон контексту за \$0.10 на вхід — це вже територія, де можна не економити на класифікації, розмітці й препроцесингу пачками.

**Google [відкрили Gemini 3.8 TTS](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-text-to-speech/) — голос можна описати словами, як промпт до картинки**

Дві моделі в API і AI Studio вже сьогодні: `gemini-3.8-flash-tts` під творчі задачі й `gemini-3.8-flash-lite-tts` під обсяг.

Що всередині:
• голос з нуля за текстовим описом, плюс 2000+ готових пресетів
• 100+ мов і діалектів
• клонування з 30-секундного семплу з перевіркою згоди
• режисура порядково — емоція, темп, діалект
• двоспікерні сцени й живі вокальні вставки (сміх, зітхання)
• SynthID-водяний знак і C2PA на весь згенерований звук

```python
from google import genai
client = genai.Client()

interaction = client.interactions.create(
    model="gemini-3.8-flash-tts",
    input=[{"type": "user_input", "content": [{
        "type": "text",
        "text": "Have a wonderful day!",
        "annotations": [{"type": "speech_metadata",
                         "style": "cheerful and friendly"}],
    }]}],
    response_format={"type": "audio"},
    generation_config={"speech_config": [{"voice": "Kore"}]},
)
```

Ціна Flash TTS — \$0.50 за мільйон текстових вхідних і \$9 за мільйон аудіо-вихідних, у Flash-Lite вихід \$6. Аудіо рахується як 25 токенів на секунду, тобто мільйон токенів — це приблизно 11 годин звуку, або ~\$0.81 за годину. З 1 січня 2027 обидва прайси подвоюються.

## 🛠️ Інструменти

**Claude Code [читав AGENTS.md тільки з увімкненою телеметрією](https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/) — і мовчки ігнорував файл, якщо її вимкнути**

Підтримку AGENTS.md додали у 2.1.277. Але лоадер сидів за віддаленим фіче-флагом `tengu_agents_md_mod`, який за замовчуванням `false`. Якщо флаг не приїхав — файл просто не читався, без жодного попередження.

Кого зачіпало: `DISABLE_TELEMETRY=1`, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1`, а також Bedrock і Vertex, де флаг не резолвиться. Автор зловив це канарковим словом у AGENTS.md і перевіркою через `claude -p`.

Обхід, який працює незалежно від флага, — один рядок у CLAUDE.md:

```bash
echo '@AGENTS.md' > CLAUDE.md
```

У [треді на HN](https://news.ycombinator.com/item?id=49814947) відповів інженер Anthropic: це артефакт розкатки, флаг був потрібен як kill-switch, фікс їде у 2.1.281 «сьогодні». На момент написання публічний changelog усе ще показує 2.1.280.

Мораль ширша за один баг: якщо ти віддав агенту інструкції файлом — перевір канарковим словом, що він їх реально бачить.

**[Strands Harness](https://strandsagents.com/blog/introducing-strands-harness/) — зібраний агентний харнес під Apache-2.0, який можна вбудувати у свій код**

Не CLI-асистент, а готовий харнес бібліотекою: контекст-менеджмент із prompt caching, вбудовані шелл, файлові й веб-тули, довготривала памʼять із відновленням сесій, делегування підзадач хелпер-агенту з чеклістом і завантаження скілів.

```bash
pip install strands-harness
# або
npm install @strands-agents/harness
npm install -g @strands-agents/cli
```

```python
from strands_harness import create_harness
agent = create_harness(model="anthropic/claude-opus-5")
agent("Research the top three vector databases, compare pricing and limits, and write it up in comparison.md")
```

Моделі підключаються рядком: Bedrock, Anthropic, OpenAI, Google, Ollama і LiteLLM. Автори заявляють 28% економії токенів проти співставних харнесів при тій самій точності.

Це не заміна Claude Code за столом, а відповідь на «мені потрібен агент усередині мого продукту, а не в терміналі» — причому без прив'язки до вендора моделі.

## 💡 Рецепти

**Рецепт: [jev-model-router](https://github.com/davila7/claude-code-templates/tree/main/cli-tool/components/mods/productivity/jev-model-router) — хай модель під кожен запит у Claude Code обирає класифікатор, а не ти**

Мод на нових function hooks: перед кожним ходом він питає Jev, наскільки задача механічна, скільки їй треба міркування і наскільки вона ризикована, і з цього обирає модель та рівень effort.

```bash
npx claude-code-templates@latest --mod productivity/jev-model-router
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude
```

Ключ кладеться в `~/.claude/settings.json`:

```json
{
  "pluginConfigs": {
    "jev-model-router@skills-dir": {
      "options": { "typesafeApiKey": "YOUR_KEY_HERE" }
    }
  }
}
```

Замість `typesafeApiKey` можна дати `gatewayApiKey` під Vercel AI Gateway — але тоді бекенд не повертає confidence, і мод обережніший із пониженням моделі.

Два суттєвих нюанси: потрібен Claude Code 2.1.259+, а `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` не опційний — без нього мод вантажиться й тихо нічого не робить. Роутинг субагентів увімкнений за замовчуванням, головної моделі — ні: зміна моделі в головному циклі посеред сесії вбиває prompt cache.

Сам не тестив: команди й конфіг узяті зі сторінки мода в репозиторії.

Ідея того варта: більшість ходів у сесії — механічні, і платити за них флагманом сенсу мало.

## 📌 Рухи й безпека

**Десктопний ZCode [пакував увесь воркспейс разом із `.git` і заливав в Alibaba Cloud](https://blog.ferstar.org/en/posts/zcode-silent-workspace-snapshot-upload/) перед запитами до моделі**

Знайшли просто: `~/.zcode` роздувся за 700 MB, а всередині `~/.zcode/v2/checkpoints/` лежав 313-мегабайтний `.enc` із метаданими 564 невдалих спроб аплоаду. Далі — реверс `app.asar` і живі сокети до нод OSS.

Що їхало в одному розібраному снапшоті на ~345 MB:
• `.git/objects/` — 102.2 MB, уся історія комітів
• `.git/lfs/` — 196.1 MB бінарників
• `.git/logs/` — рефлоги й історія гілок
• плюс сам код, конфіги і глобальні налаштування ZCode

Тобто разом із кодом виїжджали ключі, які колись закомітили й «видалили» наступним комітом. Тумблера, який це реально вимикав, у UI не було: «Repo Snapshot Indexing» керував лише індексацією на сервері, а сайдкар стартував беззастережно після логіну.

Хронологія: 18 вересня публікація і визнання від Z.ai, 21-го — відкриті сирці вже без цього пайплайну, 23-го автор перевірив 3.14.3 і підтвердив, що логіки снапшотів там немає. Зачеплена версія — 3.12.3.

Якщо ганяв ZCode на робочих репах — ротуй усе, що колись лежало в історії. І це вже другий такий випадок за місяць, тож питання «а що саме мій AI-клієнт відправляє» перестало бути параноєю.
