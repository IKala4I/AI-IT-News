## 🚀 Моделі

**Aleph Alpha [виклали Kolibri-1](https://aleph-alpha.com/en/blog/kolibri-has-landed-a-sovereign-open-weight-model/) під Apache-2.0 — MoE на 78B параметрів, з яких активні лише 3.46B**

Цифри з [картки моделі](https://huggingface.co/Aleph-Alpha/Kolibri-1):
• контекст 262 144 токени нативно, до 1 048 576 з `--max-model-len`
• 96.0% на AIME 2026, 89.3% в середньому по коду (англійська)
• 20T токенів тренування: ~62.5% англійської, ~23.9% німецької, ~13.6% коду
• explicit reasoning mode і tool calling; ваги є у FP8 і [BF16](https://huggingface.co/Aleph-Alpha/Kolibri-1-BF16)

Підняти через vLLM:

```bash
vllm serve Aleph-Alpha/Kolibri-1 --kv-cache-dtype fp8 \
  --reasoning-parser kolibri1 \
  --tool-call-parser kolibri1 \
  --enable-auto-tool-choice
```

![Kolibri-1](https://aleph-alpha.com/_astro/00-cover.Du35XCGh_zJqw.jpeg)

3.46B активних — це вже модель, яку реально тримати на одній машині під агентні задачі. Якщо шукав опенсорсну заміну клауд-моделі саме під tool calling, Kolibri варта тесту.

## 🛠️ Інструменти

**Claude Code [у 2.1.288](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) повертає промпт, зчищений Ctrl+C, і дає `/code-review` ліміт знахідок**

• передумав після Ctrl+C — Up на порожньому промпті повертає чернетку разом із вставленим текстом і картинками
• `/code-review --max-findings all` (або число) показує більше знахідок, ніж звичайний ліміт; вибір тримається до `--max-findings default`
• у cloud-сесіях, де в образі немає GitHub CLI, тепер є вбудований `gh api`
• MCP-сервер, якому посеред tool call'у забракло OAuth-скоупу, просить переавторизацію замість падіння

Ще полагодили підгрузку path-scoped `.claude/rules` і вкладених CLAUDE.md, коли файл у їхній зоні створює чи змінює Write або Edit — раніше їх тягнув тільки Read.

Остання фіча тиха, але важлива: якщо ти розклав правила по підпапках, вони нарешті діють і на запис, а не лише на читання.

Ревʼю тепер можна просити через REST і GraphQL, з опційним рівнем effort у запиті — отже, його можна вшити у свій воркфлоу чи внутрішній тул. У [доках](https://docs.github.com/en/copilot/how-tos/use-copilot-agents/request-a-code-review/use-code-review) це робиться додаванням `copilot-pull-request-reviewer[bot]` у рецензенти PR.

Дефолт змінився ще 28 вересня — на всіх нових і наявних репозиторіях та організаціях. Хто колись явно обрав Lite, той Lite і залишив.

## 💡 Рецепти

**Рецепт: [ds4 від antirez](https://dwarfstar.sh/) — крутимо DeepSeek V4 локально і підсовуємо його Claude Code замість API**

ds4 (DwarfStar 4) — вузький C-рушій інференсу під MIT: асиметрична 2-бітна квантизація routed experts, KV-кеш зі скиданням на SSD, підтримка DeepSeek V4 / V4.1 Flash, GLM 5.x і Qwen 3.8 Flash Next. Треба Mac на Apple Silicon з 96+ GB, DGX Spark або Strix Halo.

```bash
git clone https://github.com/antirez/ds4.git
cd ds4
./download_model.sh ds4f-q2
make                 # Metal; ще є cuda-spark / strix-halo / cuda-generic
./ds4-server --ctx 32768
```

Сервер слухає `http://127.0.0.1:8000`. Крім OpenAI-ендпоінтів там є [Anthropic-style](https://github.com/antirez/ds4/blob/main/docs/SERVER.md) `POST /v1/messages` з tools і SSE — тобто туди можна націлити Claude Code:

```bash
export ANTHROPIC_BASE_URL=http://127.0.0.1:8000
claude
```

![ds4](https://dwarfstar.sh/og-preview-v2.png)

Команди ds4 — з його README і `docs/SERVER.md`, `ANTHROPIC_BASE_URL` — з [доків Claude Code](https://code.claude.com/docs/en/env-vars). Саму зв'язку сам не тестив; врахуй, що на неофіційному base URL Claude Code вимикає Remote Control і MCP tool search. Є ще `./ds4-agent` — власний агентний інтерфейс, якщо чужий харнес не потрібен.
