**GitHub [дали Copilot Auto три режими](https://github.blog/changelog/2026-09-14-configure-cost-and-quality-in-copilot-auto-model-selection) — Efficiency, Balance та Intelligence**

Auto й раніше сам вибирав модель під кожен промпт. Тепер можна сказати, з якого боку він має помилятися:

• **Efficiency** — мінімум витрат на простих задачах
• **Balance** — рівно між ціною, якістю і швидкістю
• **Intelligence** — якість понад усе

Пул моделей у всіх трьох однаковий, змінюється лише логіка вибору. Платиш за ту модель, яку Auto реально взяв, а не за тариф режиму; знижка 10% на auto-вибір для платних підписок лишається.

Розкочують у VS Code, Copilot CLI та застосунку GitHub Copilot.

Корисно, якщо ти тримав Auto вимкненим саме через непередбачуваність рахунку: Efficiency на рутині й Intelligence на складному — це вже керована стратегія, а не лотерея.

**[Ordewell](https://github.com/ordewell/ordewell) — розкладає одну ціль на впорядкований план задач і роздає їх Claude Code, Codex чи OpenCode**

Планувальник спершу лазить по кодбазі, ставить уточнювальні питання і тільки потім видає план, у якому кожна задача має свій runner, модель і режим. План можна переглянути й поправити руками — код почне писатися після цього, а не до.

```bash
npm install -g ordewell
ordewell plan --goal "..."
ordewell run
```

Є ще `ordewell tui` для фулскрін-режиму, `ordewell web --daemon` для HTTP API і розширення для VS Code. Кастомні агенти підключаються через plugin manifest. Apache 2.0.

![Ordewell](https://ordewell.ai/assets/og-banner.png)

Головне тут — крок ревʼю між «хочу фічу» і «агент пішов писати». Сам не тестив, на HN сьогодні тільки з'явився, але саме цього бракує, коли одна задача явно розпадається на п'ять і хочеться різні моделі на різні шматки.

**[Capsule](https://withcapsule.app/) — застосунок цілком в одному файлі: HTML-інтерфейс, схема і SQLite-база всередині `.capsule`**

Схема така: описуєш застосунок Claude, ChatGPT чи Gemini, на виході отримуєш один `.capsule` файл. Далі його можна кинути в месенджер чи пошту — той, хто відкриє, одразу бачить і інтерфейс, і дані.

• всередині звичайні HTML і CSS плюс локальний SQLite
• повністю офлайн
• хост-плеєр є під macOS, Windows і Linux, iOS та Android обіцяють
• плеєр безплатний; про ліцензію й відкритість коду на сайті нічого

![Capsule](https://withcapsule.app/og-image.png)

Ніша вузька, але справжня: одноразовий трекер чи табличка для двох людей, які не хочуть акаунт і хостинг. Формат «файл замість деплою» для LLM-згенерованих утиліт виглядає доречніше, ніж черговий веб-сервіс.

## 💡 Рецепти

**Рецепт: [запускати субагента без жодного CLAUDE.md](https://code.claude.com/docs/en/sub-agents) — у 2.1.271 з'явився `omitClaudeMd`**

Якщо субагент бере все з делегувального промпта, то проєктні конвенції в його контексті — це просто спалені токени плюс шанс, що він почне їх виконувати замість задачі. Тепер це вимикається одним рядком у фронтметері:

```markdown
---
name: isolated-researcher
description: Research agent that works independently without project context
tools: Read, Grep, Glob, WebFetch
model: sonnet
omitClaudeMd: true
---
```

Що саме не завантажиться: user, project і local CLAUDE.md. Managed policy від організації вантажиться далі — крім managed-субагентів, у яких CLAUDE.md не читається в будь-якому разі.

Одна пастка з доків: поле ігнорується, якщо агент запущений як головний — через `--agent` або налаштування `agent`. Працює з v2.1.271.

Офіційна фіча, приклад і таблиця полів є в документації субагентів.

## 📌 Рухи й безпека

**Розслідування: [за агентними атаками на OpenAI, Anthropic і Meta стоїть одна фірма](https://www.effort.news/irregular) — ізраїльська Irregular**

Апдейт до історії з отруєними пакетами, про яку було 12 вересня. Тоді це виглядало як окремі інциденти в різних лабах. Тепер зʼясувалось, що всі вони — з оцінок безпеки, які проводила та сама компанія, Irregular (юрособа Pattern Labs Tech).

Хронологія розкриттів: Anthropic про три інциденти 30 липня, OpenAI 4 серпня, Meta 6 серпня, а 9 вересня Anthropic розширили свій звіт до чотирьох.

Ключова деталь: моделям на тестах давали живий інтернет і не обмежували скоуп. Тому замість пісочниці вони діставали реальні системи — звідси і публікація шкідливих пакетів у реєстри, і крадіжка креденшелів через колізію доменних імен.

Практичного «оновись і будь спокійний» тут немає, але напрям очевидний: пакети, які «просто зʼявилися» в реєстрі минулого літа, можуть бути не від людини і не від зловмисника, а з чийогось евалу.
