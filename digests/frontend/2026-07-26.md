## ⚛️ React

**React [зарелізили патчі 19.2.8, 19.1.9 і 19.0.8](https://github.com/facebook/react/releases/tag/v19.2.8)** — фікс DoS-вразливості в Server Functions.

Під капотом — security advisory GHSA-wx67-qw84-cm4g (High, CVSS 7.5): спеціально сформований HTTP-запит на server function endpoint міг зʼїсти всю памʼять або CPU процесу через дірку в декодуванні Flight-протоколу в `react-server-dom-webpack`, `-parcel` і `-turbopack` версій 19.0.0–19.2.7.

Якщо не юзаєш React Server Components чи Server Functions через жоден з цих трьох бандлер-плагінів — тебе це не стосується.

⚠️ **Безпека:** онови до 19.0.8 / 19.1.9 / 19.2.8, якщо в проєкті є RSC/Server Functions. [Advisory](https://github.com/facebook/react/security/advisories/GHSA-wx67-qw84-cm4g)

Брейкінгів в API нема — суто безпека, тож апдейт варто накотити відразу, а не чекати наступного релізного вікна.

## 📱 React Native та Expo

**React Native [випустили 0.87.0-rc.1 і одразу rc.2](https://github.com/facebook/react-native/releases/tag/v0.87.0-rc.2)** — головна зміна: Strict TypeScript API тепер дефолтний JS API фреймворка.

Ще в цих RC:
• прибрали недокументований `Touchable`, `rn-get-polyfills` (юзай `react-native/js-polyfills`) і окремий пакет `jest-preset`
• Metro підняли до 0.87.0, на iOS — фікси збірки під Xcode 26.3
• rc.2 фіксить краш rc.1 при старті і прибирає модуль `SceneTracker`

⚠️ **Міграція:** дефолтний JS API — Strict TypeScript API; щоб лишитись на старому, додай `customConditions: ["react-native-legacy-deep-imports"]`. [Реліз rc.2](https://github.com/facebook/react-native/releases/tag/v0.87.0-rc.2)

Це ще RC, стабільна 0.87 орієнтовно 10 серпня — саме час прогнати проєкт через Upgrade Helper, поки є запас часу на фікси.

#reactnative

**react-native-screens [випустили першу альфу 5.0.0](https://github.com/software-mansion/react-native-screens/releases/tag/5.0.0-alpha.1)** — Stack, Split, FormSheet і ScrollViewMarker переходять з experimental у звичайний імпорт з головного пакета.

Старі компоненти лишаються, але офіційно стають legacy — автори обіцяють ще кілька мінор/патч-релізів на гілці v4, але без нових фіч там.

Також у релізі:
• FormSheet на Android — `initialDetentIndex`, `onDetentChanged`, кастомний колір фону контейнера
• Stack на Android — Material 3 Expressive theming для App Bar
• фікси крашів при анмаунті екрана під час швидкої навігації

Це лише перша альфа нової мажорної версії — цікаво стежити, але в прод ще рано. Якщо вже сидиш на experimental Stack/FormSheet — почни планувати перехід на прямий імпорт.

**Expo [згортає Expo Agent](https://expo.dev/changelog/expo-agent-ending-the-closed-beta-and-winding-the-project-down)** — веб-версія AI coding IDE на agent.expo.dev перестає працювати після 31 липня.

Команда пояснює рішення прямо: вигідніше інтегруватись у харнеси, якими розробники й так щодня користуються (Claude Code, Codex), ніж підтримувати власну веб-IDE. Напрацювання підуть у Expo MCP-сервер і опенсорсні skills.

⚠️ **Міграція:** до 31 липня вивантаж проєкти з Expo Agent (або підтягни з GitHub, якщо він був звʼязаний), постав залежності локально (`bun install`/`npm install`) і підключи Expo MCP-сервер у своєму редакторі. [Деталі](https://expo.dev/changelog/expo-agent-ending-the-closed-beta-and-winding-the-project-down)

Якщо пробував Expo Agent — не забудь встигнути забрати проєкти. Якщо ні — сигнал важливіший: Expo ставить на MCP-сервер + твій звичний AI-інструмент, а не на окремий продукт.

## 🧰 Бібліотеки й тулінг

**Software Mansion [представили Detour](https://expo.dev/blog/deferred-deep-linking-the-right-way)** — SDK для deferred deep linking, заміна класичним атрибуційним SDK для кейсу «тапнув лінк без апки → поставив з стору → лінк усе одно довів до екрана».

Інтегрується прямо в точку розширення `+native-intent.tsx` Expo Router і резолвить лінк ДО першого рендеру — без гонки з `useEffect`, типової для сторонніх SDK. На Android матчинг детермінований через Play Store Install Referrer API, на iOS — імовірнісний, бо Apple не дає еквівалентного API.

Щойно вийшла 1.0, репозиторій ще молодий (252 зірки), реальних відгуків з продакшена в джерелах нема — але команда та сама, що робить Reanimated і Gesture Handler.

Якщо є deep linking з атрибуцією і бісить `useEffect`-гонка — варто придивитись. Для простих кейсів без installation gap це поки зайва залежність.
