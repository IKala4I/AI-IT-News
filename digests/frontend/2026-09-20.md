## 📱 React Native та Expo

**Expo [відкрив бету SDK 58](https://expo.dev/changelog/sdk-58-beta) — на React Native 0.88 RC і з прицілом на iOS 27**

Найбільший реліз Expo за кілька місяців. Головне:
• збірка під iOS 27: scene-based lifecycle і автоматичний ресайз вікна
• `expo-app-intents` — App Intents з Expo-апки: Siri, Shortcuts, Spotlight
• Expo UI отримав нативні `NavigationStack` і `Toolbar` для iOS плюс нові Jetpack Compose компоненти для Android
• prebuilt `expo-modules-core` ріже clean-білд на Android приблизно вдвічі
• Expo Modules 2.0 beta — синхронні виклики на iOS у 2.5–5.6× швидші
• Noxcturnal, експериментальний трансформер на Rust — холодний бандлінг ~2× швидше
• в Expo Router стабілізувались data loaders, SSR, middleware і native tabs

⚠️ **Міграція:** на iOS обовʼязковий scene-based lifecycle, на Android R8-мініфікація тепер за замовчуванням, `File.write()` в `expo-file-system` став async, Strict TypeScript API увімкнено за замовчуванням. Мінімум Node.js 22.13+, 24.3+ або 26+. [Чейнджлог](https://expo.dev/changelog/sdk-58-beta)

```bash
npx expo install expo@next --fix
```

Бета триватиме три-чотири тижні, стабільний реліз — коли вийде RN 0.88. На прод зарано, але підняти гілку і прогнати білд варто вже: scene lifecycle і async `File.write()` зачеплять багатьох.

## 🧰 Бібліотеки й тулінг

**Reanimated [випустив 4.7.0](https://github.com/software-mansion/react-native-reanimated/releases/tag/4.7.0) — новий движок layout-анімацій тепер за замовчуванням**

Новий движок замінює legacy-проксі. Разом з ним приїхало:
• `useAnimatedStyle` вміє анімувати `backgroundImage` — лінійні й радіальні градієнти обʼєктом або CSS-рядком
• пачка фіксів shared element transitions: репарентинг вʼю, відновлення кольорів на Android
• CSS-переходи кольору і радіусу нативним шляхом Android за флагом `ANDROID_CSS_PLATFORM_TRANSITIONS`

⚠️ **Міграція:** `AnimatedRefOnUI` став Shareable — читається через `.value`, а не викликається як функція; `AnimatedRefOnJS` перейменували на `AnimatedRefOnRN`; флаг `USE_SYNCHRONIZABLE_FOR_MUTABLES` прибрали, мутабли завжди на Synchronizable. Підтримка RN 0.83–0.85 зникла, лишились 0.86–0.88. [Реліз-ноти](https://github.com/software-mansion/react-native-reanimated/releases/tag/4.7.0)

Якщо активно юзаєш layout-анімації — оновлюйся на окремій гілці й дивись уважно: движок помінявся під капотом. Відкотитись є чим, див. рецепт нижче.

**Metro [зарелізив 0.87.1](https://github.com/facebook/metro/releases/tag/v0.87.1) — мінус 34% памʼяті на краулінгу файлів**

Найцінніше тут — цифри. Викинули залежність `walker`, і памʼять під час краулу впала приблизно на 34%, піковий хіп — на 41%.

З нового: `resolver.schemeResolvers` дозволяє свої резолвери для специфікаторів з URI-схемою типу `foo:bar`, а імпорти `metro:babel-runtime/...` Metro тепер резолвить у власну залежність `@babel/runtime`.

Фікси: Fast Refresh на lazy-бандлах, інлайнінг `Platform.OS` більше не ламає таргети запису, `FallbackWatcher` перестав губити файли при краулі директорій. Залежність `image-size` замінили на вендорені парсери — закрили CVE.

⚠️ **Міграція:** експериментальний `transformer.unstable_renameRequire` прибрали (require і так ніколи не перейменовувався), юніон `Resolution` розширили типом `virtualModule`. [Реліз](https://github.com/facebook/metro/releases/tag/v0.87.1)

Мінус третина памʼяті на краулі відчутна на великих монорепах. Окремо ставити не треба — приїде з RN 0.88.

**[Screenmap](https://github.com/aleqsio/screenmap) — GitHub Action, що скриншотить кожен екран апки і кидає їх у PR**

Що робить і що замінює: піднімає апку в CI, обходить екрани, яких торкається діф, і постить скриншоти прямо в рев'ю. Замінює ритуал «збери білд, поклікай сам» — але тільки в частині візуальної перевірки.

Наскільки стабільна: версія `v1`, MIT, без обіцянок щодо API. Обмеження автор перелічує чесно: потрібен роутер, який Screenmap уміє прочитати (expo-router або мапа маршрутів react-navigation), для iOS — macOS-раннери за 10× ціни Linux, глушіння Android dev-menu «best-effort», флоу з iOS не гарантовано відтворюються на Android. І прямим текстом: «It reports, it does not gate» — це звіт, а не блокуючий чек.

Покращує не апку, а рев'ю: скриншоти лежать гілкою у твоєму ж репо і ганяються у твоїх Actions.

## 💡 Рецепти

**Відкотити Reanimated 4.7 на старий движок layout-анімацій, не відкочуючи версію**

Якщо після апдейту на 4.7 layout-анімації поїхали, вертатись на 4.6 не обовʼязково. У Reanimated є статичний feature flag, який повертає legacy-проксі. Додай у `package.json` застосунку:

```json
{
  "reanimated": {
    "staticFeatureFlags": {
      "USE_LEGACY_LAYOUT_ANIMATIONS_PROXY": true
    }
  }
}
```

Флаг статичний, тож рестартом Metro не обійдешся — потрібен `pod install` на iOS і повний ребілд нативної частини:

```bash
npx pod-install
```

Одне застереження прямо з реліз-нотів: цей флаг не можна юзати разом із shared element transitions. Якщо в тебе є і те, і те — доведеться розбиратися з новим движком.

Звідки: синтаксис — з [гайда по feature flags](https://docs.swmansion.com/react-native-reanimated/docs/guides/feature-flags/) у доках Reanimated, сам флаг названо в [реліз-нотах 4.7.0](https://github.com/software-mansion/react-native-reanimated/releases/tag/4.7.0) як спосіб тимчасово відкотитись. Сам не ганяв.
